# 눈높이가 바닥에 있는 공학 연구소

공학, 배우려니 너무 어렵죠?
그래서 제 연구소는 눈높이를 바닥까지 낮췄어요.
저부터 이해가 안 됐거든요.
그림과 숫자로 최대한 풀어 쓰고, 하나씩 차근차근 함께 배우는 전자공학·AI 연구소예요.

- 블로그: https://ezenglab.blogspot.com/
- 강좌마다 폴더 하나: `index.md`(강좌 원본)와 그 강좌의 그림

## 올리는 방법
- `python3 tools/blogger.py html <폴더>`: 블로그용 HTML 미리 보기(build/)
- `python3 tools/blogger.py draft <폴더>`: 블로거 임시저장 글 만들기·고치기
- `python3 tools/blogger.py publish <폴더>`: 게시
- `posts.json`: 강좌 폴더와 블로그 글 번호 연결표
- 그림 주소는 jsDelivr로 커밋에 고정해서 불러와요.

## 새 강좌 양식
1. 폴더 `<분야>-<번호>-<이름>/index.md`를 만들어요. 머리말에는 `title`("큰 제목: 부제"), `field`(인공지능·전자공학·전자 부품), `order`, `level`, `tags`, `summary`를 넣어요.
   - `summary`는 1단원 첫 문단이에요. 목차 앞에 나오고 블로그 목록의 소개 글이 돼요.
2. 단원 번호는 1부터 시작해요(`## 1.`, `### 1-1.`). 목차는 소제목 그대로 만들어져요.
3. 표 칸에 `4장`, `7-3`처럼 단원 번호만 쓰면 그 단원으로 가는 링크가 돼요.
4. 표지: `tools/cover.py`의 `COVERS`에 그림과 한 줄 문구를 넣고 `python3 tools/cover.py <폴더>`를 실행해요.
   - 1200×630, 페이퍼로지(`tools/fonts`)
   - 왼쪽 630×630은 분야 색 바탕에 분야와 큰 제목만 들어가요. 블로그 목록 정사각형 썸네일 영역이에요.
   - 오른쪽에는 그림, 부제, 문구가 945×600 잘림 범위 안에 들어가요.
   - 표지는 본문 첫 그림이라 블로그 썸네일과 공유 미리보기 사진이 돼요.
5. 커밋·푸시 → `draft` → 확인 → `publish`
