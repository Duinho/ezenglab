# 작업 방법

강좌 원고는 GitHub에서 바로 읽을 수 있는 마크다운으로 쓰고, `blogger.py`가 블로그용 HTML로 바꿔서 올려요.

## 폴더와 파일

- 강좌 폴더 이름: `분야 번호 짧은 제목` (예: `인공지능 140 로지스틱 회귀`)
- 폴더 안: `index.md`(원고), `cover.png`(표지), 그림 파일들
- `posts.json`: 강좌 폴더와 블로그 글 번호·주소 연결표
- 그림 주소는 jsDelivr로 커밋에 고정해서 불러와요. 그래서 그림을 바꾸면 먼저 커밋·푸시해야 해요.

## 원고 표기

````markdown
<!--
title: "큰 제목: 부제"
field: 인공지능
order: 140
level: 기초
tags: [머신러닝, 분류]
summary: "1단원 첫 문단(목차 앞 소개 문장이자 블로그 목록 소개 글)"
-->

# 큰 제목: 부제

![큰 제목: 부제](cover.png)

<!-- 목차 -->

## 1. 단원 제목

![그림 캡션](그림파일.png)

<details>
<summary>정답 보기</summary>

정답 내용

</details>

> 요약 상자 첫 줄(블로그에선 굵게)
>
> - 요약 항목

> ⚠️ 이렇게 시작하면 노란 경고 상자

다른 강좌 링크: [강좌 제목](<../인공지능 130 선형 회귀/index.md>)
````

- 머리말은 `<!-- -->` 안에 둬서 GitHub 화면에는 보이지 않아요.
- 맨 위 `# 제목`과 표지 그림 줄은 GitHub용이에요. 블로그에선 블로그 제목과 표지 처리로 대신해요.
- `<!-- 목차 -->` 자리에 블로그용 목차가 들어가요.
- 그림 줄은 `![캡션](파일)` 한 줄로만 써요. 블로그에서 캡션이 그림 아래 붙어요.
- 다른 강좌 링크는 블로그에 게시된 강좌면 블로그 주소로, 아니면 「제목」 글자로 바뀌어요.
- 단원 번호는 1부터 써요(`## 1.`, `### 1-1.`). 표 칸에 `4장`, `7-3`처럼 단원 번호만 쓰면 그 단원으로 가는 링크가 돼요.
- 수식은 `$$` 블록으로 써요. GitHub와 블로그 둘 다 수식으로 보여요.

## 명령

명령은 저장소 맨 위 폴더에서 실행해요. 폴더 이름에 띄어쓰기가 있어서 따옴표로 감싸요.

- `python3 tools/blogger.py html "인공지능 140 로지스틱 회귀"`: 블로그용 HTML 미리 보기(build/)
- `python3 tools/blogger.py draft "인공지능 140 로지스틱 회귀"`: 블로거 임시저장 글 만들기·고치기(이미 게시된 글은 내용만 고쳐짐)
- `python3 tools/blogger.py publish "인공지능 140 로지스틱 회귀"`: 게시
- `python3 tools/cover.py "인공지능 140 로지스틱 회귀"`: 표지 만들기(`cover.py`의 `COVERS`에 그림과 한 줄 문구를 먼저 넣어요)
- `python3 tools/check_thumbs.py`: 게시 후 썸네일 잘림 검사

## 표지

- 1200×630, 페이퍼로지(`tools/fonts`)
- 왼쪽 630×630은 분야 색 바탕에 분야와 큰 제목만 들어가요. 블로그 목록 정사각형 썸네일 영역이에요.
- 오른쪽에는 그림·부제·문구가 들어가요. 홈 맨 위 큰 썸네일(945×600)에서 잘리지 않는 범위예요.
- 블로거는 내용을 보고 자를 위치를 정해요. 오른쪽 그림은 상자 가운데에 모이게 그려요.

## 새 강좌 순서

1. 폴더와 원고, 그림, 표지 만들기
2. 커밋·푸시 → `draft` → 임시저장 글 확인 → `publish`
3. 앞 강좌의 "다음 강좌"를 새 강좌 링크로 바꾸고 앞 강좌도 `draft`로 다시 반영
4. `check_thumbs.py`로 썸네일 확인
