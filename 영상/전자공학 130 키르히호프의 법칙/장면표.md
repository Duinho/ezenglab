# 키르히호프의 법칙 영상 장면표

## 공통 규칙

- **읽기** 줄은 타입캐스트에 넣는 문장이에요. 자막은 읽기 줄에서 표기 규칙으로 바꿔 만들어요.
- 숫자는 소리를 한글로 직접 적어요(예: `[육 볼트|6V]`).
- `{천천히: …}`는 핵심 용어를 처음 소개할 때 한 번만 써요. L01에서 강좌 이름을 말할 때는 천천히 읽지 않아요.
- 모든 장면에 **자막** 줄이 있어요. 자막은 ` / ` 자리에서만 끊어요.
- **멈춤** 줄이 있으면 그 장면 음성 뒤에 그만큼 말없이 화면만 보여 줘요.
- 색은 전자공학 110·120과 같아요. 전압 빨강, 전류 파랑, 저항 주황. 장면 코드와 스타일은 `영상/전자공학 120 옴의 법칙/`(없으면 110)을 바탕으로 해요.
- 페이퍼로지에 없는 기호(Ω, ✕, ⚠)는 쓰지 않아요. 화면의 저항 값은 「1킬로옴」「220옴」처럼 한글로 적어요. 「×」「÷」「+」「−」「=」는 써도 돼요.
- 자전거·트럭은 단순한 선 그림으로 그려요. 사진은 쓰지 않아요.
- 숫자와 사실은 원고에 있는 것만 써요.

### 표기 규칙 (읽기 → 자막)

- `[읽는 소리|자막 글자]`: 그 자리만 따로 바꿔요.

## 장면

### L01 · 여는 질문

- 읽기: 지난 영상에서 옴의 법칙으로 부품 하나의 전압, 전류, 저항을 계산했어요. 그럼 저항이 두 개, 세 개로 늘어나면 전류와 전압은 어떻게 나뉠까요? 오늘은 회로가 지키는 두 가지 규칙, 키르히호프의 법칙을 알아볼게요.
- 자막: 지난 영상에서 옴의 법칙으로 / 부품 하나의 전압, 전류, 저항을 계산했어요 / 그럼 저항이 두 개, 세 개로 늘어나면 / 전류와 전압은 어떻게 나뉠까요? / 오늘은 회로가 지키는 두 가지 규칙, / 키르히호프의 법칙을 알아볼게요
- 화면: 저항 하나짜리 작은 회로 「V = I × R」 → 저항이 두세 개로 늘며 갈래가 생긴 회로에 물음표 → 강좌 제목 「키르히호프의 법칙」 아래 두 칩 「갈림길」 「한 바퀴」
- 움직임: "부품 하나"에서 작은 회로, "늘어나면"에서 저항이 늘어남, "나뉠까요"에서 물음표, "두 가지 규칙"에서 두 칩, "키르히호프"에서 제목

### L03 · 한 줄로 먼저

- 읽기: 먼저 한 줄로 볼게요. {천천히: 키르히호프의 법칙}은 회로가 지키는 두 가지 규칙이에요. 하나는 전류 법칙이에요. 갈림길로 들어온 전류와 나간 전류는 같아요. 다른 하나는 전압 법칙이에요. 회로를 한 바퀴 돌면 올라간 전압과 내려간 전압이 같아요.
- 자막: 먼저 한 줄로 볼게요 / 키르히호프의 법칙은 / 회로가 지키는 두 가지 규칙이에요 / 하나는 전류 법칙이에요 / 갈림길로 들어온 전류와 나간 전류는 같아요 / 다른 하나는 전압 법칙이에요 / 회로를 한 바퀴 돌면 / 올라간 전압과 내려간 전압이 같아요
- 화면: 두 칸 카드. 왼쪽 「전류 법칙」(파랑) 갈림길 아이콘 「들어온 전류 = 나간 전류」, 오른쪽 「전압 법칙」(빨강) 고리 아이콘 「올라간 전압 = 내려간 전압」
- 움직임: "키르히호프의 법칙"에서 명찰, "전류 법칙"에서 왼쪽 카드, "전압 법칙"에서 오른쪽 카드

### L04 · 옴의 법칙과 다른 점

- 읽기: 옴의 법칙이 부품 하나에서 전압, 전류, 저항의 관계를 알려 준다면, 키르히호프의 법칙은 여러 부품이 이어진 회로 전체에서 전류와 전압이 어떻게 나뉘는지 알려 줘요.
- 자막: 옴의 법칙이 부품 하나에서 / 전압, 전류, 저항의 관계를 알려 준다면, / 키르히호프의 법칙은 여러 부품이 이어진 / 회로 전체에서 / 전류와 전압이 어떻게 나뉘는지 알려 줘요
- 화면: 왼쪽 돋보기 안에 저항 하나 「옴의 법칙 · 부품 하나」, 오른쪽 회로 전체를 감싼 점선 상자 「키르히호프의 법칙 · 회로 전체」
- 움직임: "부품 하나에서"에서 왼쪽, "회로 전체에서"에서 오른쪽 점선 상자

### L05 · 자전거 갈림길 (쇼츠 S1)

- 읽기: 이번에도 자전거로 시작할게요. 자전거 [열 대|10대]가 갈림길로 들어왔어요. 위쪽 길로 [여섯 대|6대]가 갔다면 아래쪽 길로는 몇 대가 갔을까요?
- 자막: 이번에도 자전거로 시작할게요 / 자전거 10대가 갈림길로 들어왔어요 / 위쪽 길로 6대가 갔다면 / 아래쪽 길로는 몇 대가 갔을까요?
- 화면: 원고 k1_junction 구성. 왼쪽에서 오는 길이 오른쪽에서 위·아래 두 갈래로 나뉨. 들어오는 길에 「10대」, 위 갈래 「6대」, 아래 갈래 「? 대」. 자전거는 작은 아이콘 점으로 흐름 표시(파랑), 3초 카운트다운
- 움직임: "열 대가"에서 들어오는 길의 자전거들이 흐름, "여섯 대가"에서 위 갈래로 흐름, "몇 대가"에서 물음표와 카운트다운
- 멈춤: 3초

### L06 · 갈림길 정답 (쇼츠 S1)

- 읽기: [네 대|4대]예요. 갈림길에서 자전거가 사라지거나 새로 생기지 않아요. 그래서 들어온 [열 대|10대]는 나간 [여섯 대|6대]와 [네 대|4대]를 더한 값과 같아요.
- 자막: 4대예요 / 갈림길에서 자전거가 / 사라지거나 새로 생기지 않아요 / 그래서 들어온 10대는 / 나간 6대와 4대를 더한 값과 같아요
- 화면: 아래 갈래 「4대」, 아래에 큰 식 「10 = 6 + 4」
- 움직임: "네 대예요"에서 아래 갈래 값, "더한 값과"에서 식

### L07 · 동네 한 바퀴 (쇼츠 S2)

- 읽기: 이번에는 동네를 한 바퀴 도는 코스예요. 출발해서 오르막을 [구 미터|9m] 올라가요. 그다음 내리막을 두 번, [삼 미터|3m]와 [육 미터|6m] 내려와서 출발한 자리로 돌아와요. 제자리로 돌아왔으니 올라간 높이와 내려간 높이는 같아야 해요.
- 자막: 이번에는 동네를 한 바퀴 도는 코스예요 / 출발해서 오르막을 9m 올라가요 / 그다음 내리막을 두 번, / 3m와 6m 내려와서 / 출발한 자리로 돌아와요 / 제자리로 돌아왔으니 / 올라간 높이와 내려간 높이는 같아야 해요
- 화면: 원고 k2_loop 구성. 높이 변화 꺾은선(출발 0 → +9m → +6m → 0m), 구간 이름표 「오르막 +9m」(빨강) 「내리막 −3m」 「내리막 −6m」, 출발점 깃발. 작은 자전거 점이 선을 따라 감
- 움직임: "구 미터"에서 오르막 구간, "삼 미터와"에서 첫 내리막, "육 미터"에서 둘째 내리막, "돌아와요"에서 자전거 점이 깃발에 도착, "같아야 해요"에서 「+9 = 3 + 6」

### L08 · 두 예시의 규칙

- 읽기: 두 예시에서 규칙을 찾을 수 있어요. 첫째, 갈림길로 들어온 양은 나간 양을 모두 더한 값과 같아요. 둘째, 한 바퀴 돌아 제자리에 오면 올라간 높이와 내려간 높이가 같아요. 전압은 두 지점의 높이 차이라고 했죠? 그래서 둘째 규칙의 높이를 전압으로 바꿔 읽으면 돼요.
- 자막: 두 예시에서 규칙을 찾을 수 있어요 / 첫째, 갈림길로 들어온 양은 / 나간 양을 모두 더한 값과 같아요 / 둘째, 한 바퀴 돌아 제자리에 오면 / 올라간 높이와 내려간 높이가 같아요 / 전압은 두 지점의 높이 차이라고 했죠? / 그래서 둘째 규칙의 높이를 / 전압으로 바꿔 읽으면 돼요
- 화면: 두 줄 카드 「1 들어온 양 = 나간 양의 합」 「2 올라간 높이 = 내려간 높이」. 마지막에 둘째 줄의 「높이」 위에 빨간 「전압」이 덮어 씌워짐
- 움직임: "첫째"·"둘째"에서 한 줄씩, "높이 차이라고"에서 110의 비탈 아이콘, "전압으로 바꿔"에서 글자가 바뀜

### L09 · 갈림길은 전류로 (쇼츠 S1)

- 읽기: 이제 회로로 바꿔 볼게요. [육 볼트|6V] 전원에 [일 킬로옴|1킬로옴]과 [일 점 오 킬로옴|1.5킬로옴] 저항을 나란히 연결했어요. 두 저항에는 같은 [육 볼트|6V]가 걸려요. 그래서 옴의 법칙으로 각각의 전류를 구할 수 있어요.
- 자막: 이제 회로로 바꿔 볼게요 / 6V 전원에 1킬로옴과 1.5킬로옴 저항을 / 나란히 연결했어요 / 두 저항에는 같은 6V가 걸려요 / 그래서 옴의 법칙으로 / 각각의 전류를 구할 수 있어요
- 화면: 원고 k3_kcl 구성. 왼쪽 전원 「6V」(빨강), 위 전선이 갈림점에서 두 갈래로 나뉘어 저항 「1킬로옴」「1.5킬로옴」(주황)이 나란히, 아래에서 다시 합쳐짐. 두 저항 옆에 「6V」 꼬리표
- 움직임: "전원에"에서 전원, "나란히"에서 두 저항, "같은 육 볼트가"에서 두 저항 옆 6V 꼬리표가 동시에

### L10 · 나뉘고 합쳐지는 전류 (쇼츠 S1)

- 읽기: [일 킬로옴|1킬로옴] 쪽은 [육 볼트 나누기 천 옴|6V ÷ 1,000옴], [육 밀리암페어|6mA]예요. [일 점 오 킬로옴|1.5킬로옴] 쪽은 [육 볼트 나누기 천오백 옴|6V ÷ 1,500옴], [사 밀리암페어|4mA]예요. 그러면 갈라지기 전 전선에는 [육 더하기 사|6mA + 4mA], [십 밀리암페어|10mA]가 흘러요. 자전거 [열 대|10대]가 [여섯 대|6대]와 [네 대|4대]로 나뉜 것과 같은 모양이에요. 두 갈래가 다시 만나는 곳에서는 다시 [십 밀리암페어|10mA]가 돼요.
- 자막: 1킬로옴 쪽은 / 6V ÷ 1,000옴, 6mA예요 / 1.5킬로옴 쪽은 / 6V ÷ 1,500옴, 4mA예요 / 그러면 갈라지기 전 전선에는 / 6mA + 4mA, 10mA가 흘러요 / 자전거 10대가 6대와 4대로 / 나뉜 것과 같은 모양이에요 / 두 갈래가 다시 만나는 곳에서는 / 다시 10mA가 돼요
- 화면: L09 회로에 파란 전류 값 「6mA」「4mA」, 갈림점 앞 「10mA」, 합쳐진 뒤 「10mA」. 오른쪽 작은 자전거 갈림길 아이콘 「10 = 6 + 4」
- 움직임: "육 밀리암페어"에서 위 갈래 값과 파란 점 흐름, "사 밀리암페어"에서 아래 갈래, "십 밀리암페어가"에서 갈림점 앞 값, "자전거"에서 아이콘, "다시 만나는"에서 합쳐진 뒤 값

### L11 · 한 바퀴는 전압으로 (쇼츠 S2)

- 읽기: 이번에는 [구 볼트|9V] 전원에 [일 킬로옴|1킬로옴]과 [이 킬로옴|2킬로옴] 저항을 한 줄로 이었어요. 갈림길이 없으니 두 저항에는 같은 전류가 흘러요. 전체 저항은 [삼 킬로옴|3킬로옴]이고, 전류는 [구 볼트 나누기 삼천 옴|9V ÷ 3,000옴], [삼 밀리암페어|3mA]예요.
- 자막: 이번에는 9V 전원에 1킬로옴과 2킬로옴 저항을 / 한 줄로 이었어요 / 갈림길이 없으니 / 두 저항에는 같은 전류가 흘러요 / 전체 저항은 3킬로옴이고, / 전류는 9V ÷ 3,000옴, 3mA예요
- 화면: 원고 k4_kvl 구성. 사각 회로 왼쪽 전원 「9V」, 위 「1킬로옴」, 오른쪽 「2킬로옴」 한 줄. 아래 계산 줄 「1킬로옴 + 2킬로옴 = 3킬로옴」 「9V ÷ 3,000옴 = 3mA」
- 움직임: "한 줄로"에서 회로, "같은 전류가"에서 파란 점이 한 줄로 흐름, "삼 킬로옴이고"에서 첫 계산 줄, "삼 밀리암페어"에서 둘째 줄과 회로 위 「3mA」

### L12 · 올라간 만큼 내려가요 (쇼츠 S2)

- 읽기: [구 볼트 일 암페어|9V 1A] 어댑터를 연결했다고 회로에 [일 암페어|1A]가 흐르는 건 아니에요. [일 암페어|1A]는 그만큼까지 줄 수 있다는 뜻이에요. 실제로 흐르는 전류는 연결한 부품과 저항이 정해요. 엘리베이터에 정원 [십오 명|15명]이라고 적혀 있어도 [세 명|3명]이 타면 [세 명|3명]만 내리는 것과 같아요.
- 자막: 9V 1A 어댑터를 연결했다고 / 회로에 1A가 흐르는 건 아니에요 / 1A는 그만큼까지 줄 수 있다는 뜻이에요 / 실제로 흐르는 전류는 / 연결한 부품과 저항이 정해요 / 엘리베이터에 정원 15명이라고 적혀 있어도 / 3명이 타면 3명만 내리는 것과 같아요
- 화면: 어댑터 그림 「9V 1A」, 「1A = 최대치」 꼬리표, 오른쪽 엘리베이터 문 「정원 15명」 안에 사람 아이콘 셋
- 움직임: "줄 수 있다는"에서 꼬리표, "부품과 저항이"에서 작은 회로, "엘리베이터에"에서 엘리베이터, "세 명이"에서 사람 셋

### L24 · 전압이 바뀌면 다시 계산

- 읽기: 대신 볼트는 미는 힘이라서 바뀌면 전류도 바뀌어요. [오 볼트|5V]에 맞춰 계산한 LED 회로를 [구 볼트|9V] 어댑터에 그대로 연결하면, 약 [삼십일 점 팔 밀리암페어|31.8mA]가 흘러서 LED 최대치를 넘어요. 전압이 바뀌면 저항을 다시 계산해요.
- 자막: 대신 볼트는 미는 힘이라서 / 바뀌면 전류도 바뀌어요 / 5V에 맞춰 계산한 LED 회로를 / 9V 어댑터에 그대로 연결하면, / 약 31.8mA가 흘러서 / LED 최대치를 넘어요 / 전압이 바뀌면 저항을 다시 계산해요
- 화면: LED+220옴 회로 전원이 「5V」 → 「9V」, 계산 줄 「(9V − 2V) ÷ 220옴 ≈ 31.8mA」, 「최대 20mA 넘음」 빨간 꼬리표
- 움직임: "구 볼트 어댑터에"에서 전원 값이 바뀜, "삼십일 점 팔"에서 계산 줄, "최대치를 넘어요"에서 빨간 꼬리표

### L25 · 비유는 감 잡기용

- 읽기: 자전거와 트럭은 규칙을 느끼게 해 주는 그림이에요. 실제 회로에서는 전류가 자전거처럼 한 대씩 나뉘지 않아요. 정확한 값은 늘 옴의 법칙과 두 법칙으로 계산해요.
- 자막: 자전거와 트럭은 / 규칙을 느끼게 해 주는 그림이에요 / 실제 회로에서는 전류가 / 자전거처럼 한 대씩 나뉘지 않아요 / 정확한 값은 늘 / 옴의 법칙과 두 법칙으로 계산해요
- 화면: 자전거·트럭 아이콘 「감 잡기용」 → 「V = I × R」 「KCL」 「KVL」 세 칩
- 움직임: "그림이에요"에서 아이콘, "정확한 값은"에서 세 칩

### L26 · 한눈에 정리

- 읽기: 한눈에 정리해 볼게요. 전류 법칙은 갈림길로 들어온 전류가 나간 전류의 합과 같다는 거예요. 전압 법칙은 한 바퀴 돌 때 올라간 전압이 내려간 전압의 합과 같다는 거예요. 직렬은 전류가 같고 전압을 나눠 가져요. 병렬은 전압이 같고 전류가 나눠 흘러요.
- 자막: 한눈에 정리해 볼게요 / 전류 법칙은 갈림길로 들어온 전류가 / 나간 전류의 합과 같다는 거예요 / 전압 법칙은 한 바퀴 돌 때 올라간 전압이 / 내려간 전압의 합과 같다는 거예요 / 직렬은 전류가 같고 전압을 나눠 가져요 / 병렬은 전압이 같고 전류가 나눠 흘러요
- 화면: 요약 상자(원고 10장) 「전류 법칙 KCL: 들어온 전류 = 나간 전류의 합」 「전압 법칙 KVL: 올라간 전압 = 내려간 전압의 합」 「직렬: 전류 같음, 전압 나눔」 「병렬: 전압 같음, 전류 나눔」
- 움직임: 말하는 순서대로 한 줄씩

### L27 · 퀴즈

- 읽기: 마지막으로 퀴즈 하나예요. 갈림길로 [이십 밀리암페어|20mA]가 들어와서 한쪽 갈래로 [십이 밀리암페어|12mA]가 흘러요. 다른 갈래로는 몇 밀리암페어가 흐를까요?
- 자막: 마지막으로 퀴즈 하나예요 / 갈림길로 20mA가 들어와서 / 한쪽 갈래로 12mA가 흘러요 / 다른 갈래로는 몇 밀리암페어가 흐를까요?
- 화면: 「퀴즈」, 갈림길 그림 들어오는 「20mA」, 위 「12mA」, 아래 「? mA」, 3초 카운트다운
- 움직임: 숫자를 말할 때 값, 카운트다운
- 멈춤: 3초

### L27B · 퀴즈 정답

- 읽기: [팔 밀리암페어|8mA]예요. [이십은 십이 더하기 팔|20mA = 12mA + 8mA]이니까요.
- 자막: 8mA예요 / 20mA = 12mA + 8mA이니까요
- 화면: 아래 갈래 「8mA」, 식 「20 = 12 + 8」
- 움직임: "팔 밀리암페어"에서 값, "이십은"에서 식

### L28 · 마무리와 다음 영상

- 읽기: 오늘은 갈림길 규칙과 한 바퀴 규칙, 키르히호프의 법칙을 살펴봤어요. 계산 과정과 퀴즈는 설명란의 블로그 글에 정리해 두었어요. 그럼 직렬로 이은 저항들은 전압을 얼마씩 나눠 가질까요? 다음 영상에서는 전압 분배를 다뤄요.
- 자막: 오늘은 갈림길 규칙과 한 바퀴 규칙, / 키르히호프의 법칙을 살펴봤어요 / 계산 과정과 퀴즈는 / 설명란의 블로그 글에 정리해 두었어요 / 그럼 직렬로 이은 저항들은 / 전압을 얼마씩 나눠 가질까요? / 다음 영상에서는 전압 분배를 다뤄요
- 화면: 블로그 글 카드 + 「설명란 링크」, 직렬 저항 둘에 「? V」「? V」, 다음 영상 카드 「전압 분배」
- 움직임: "블로그"에서 카드, "나눠 가질까요"에서 물음표, "전압 분배"에서 다음 영상 카드
