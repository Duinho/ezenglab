# 선형 회귀 개념편 영상 장면표

## 공통 규칙

- **읽기** 줄은 타입캐스트에 넣는 문장이에요. 자막은 읽기 줄에서 아래 표기 규칙으로 바꿔 만들어요.
- 숫자는 소리를 한글로 직접 적어요. 값·기울기·온도·거리는 한자어, 개수와 시간(한 시간, 두 시간)은 고유어로 읽어요.
- 천천히 읽기(`{천천히: …}`)는 쓰지 않아요(2026-11-11 팀장님 결정).
- **자막** 줄은 모든 장면에 써요. 주어·목적어와 서술어, 용어와 조사가 갈라지지 않게 뜻 단위로 끊어요.
- **의도** 줄은 그 장면이 무엇을 보여 주려는지 한 줄로 적은 거예요(읽지 않음, 화면에 쓰지 않음). 화면이 이 한 줄을 전달하는지 먼저 봐요.
- 그래프 규칙: 점은 파랑, 직선은 초록(#14936a), 오차 막대는 빨강, 평균점은 ★. 축 이름과 단위(시간·km, °C·개)를 꼭 적어요. 그래프는 원고 그림(l1~l9, l_rotate.gif)의 값과 모양을 그대로 SVG로 다시 그려요.
- 글꼴은 페이퍼로지만 써요. 온도는 화면·자막 모두 `°C`(생활 기기 110과 같음), 음수는 `-28`처럼 하이픈으로 써요. `R²`의 위첨자 ²가 페이퍼로지에 없으면 R 옆에 작은 2를 도형으로 그려요. 깨진 글자(□)는 실패예요.
- 계산은 결과만 보여 주고 「계산편」과 「설명란의 블로그 글」로 넘겨요.
- 원고 9-3의 U자 전력 수요 그림은 모양을 보여 주려고 만든 예시라서 화면 구석에 「모양 예시」 이름표를 붙여요.

### 표기 규칙 (읽기 → 자막)

- `[읽는 소리|자막 글자]`: 그 자리만 따로 바꿔요.

## 장면

### L01 · 여는 질문

- 의도: 생활 속 숫자 예측 질문(내일 아이스크림 몇 개)으로 궁금증을 만들고 제목으로 넘긴다
- 읽기: 내일 기온이 [이십칠 도|27°C]래요. 아이스크림 가게는 몇 개를 준비하면 좋을까요? 오늘은 점들 사이에 직선 하나를 그어서 숫자를 예측하는 방법, 선형 회귀를 알아볼게요.
- 자막: 내일 기온이 27°C래요 / 아이스크림 가게는 / 몇 개를 준비하면 좋을까요? / 오늘은 점들 사이에 직선 하나를 그어서 / 숫자를 예측하는 방법, / 선형 회귀를 알아볼게요
- 화면: 아이스크림 가게 진열대와 온도계 「내일 27°C」, 물음표 → 빈 그래프에 점 다섯 개가 찍히고 초록 직선이 그어짐 → 강좌 제목 「선형 회귀 개념편」
- 움직임: "27°C"에서 온도계 눈금이 올라감, "몇 개를"에서 물음표, "직선 하나를"에서 점과 직선, "선형 회귀를"에서 제목

- 읽기: 안녕하세요, [눈바공 연구소|눈바공 연구소] [바닥 연구소장입니다.|바닥 연구소장입니다.]

- 움직임: 공통 인트로(tools/video/intro.js)

- 멈춤: 1초

### L03 · 먼저 한 줄로

- 의도: 결론(점들 사이 직선으로 숫자 예측)을 먼저 주고, 앞 강좌 kNN과 무엇이 다른지 한 문장으로 잇는다
- 읽기: 먼저 한 줄로 정리할게요. 선형 회귀는 데이터 점들 사이를 가장 잘 지나는 직선을 찾고, 그 직선으로 새 값의 숫자를 예측하는 방법이에요. 앞 강좌의 [케이엔엔|kNN]이 사과일까 귤일까처럼 종류를 골랐다면, 선형 회귀는 몇 개 팔릴까처럼 숫자를 맞혀요.
- 자막: 먼저 한 줄로 정리할게요 / 선형 회귀는 데이터 점들 사이를 / 가장 잘 지나는 직선을 찾고, / 그 직선으로 새 값의 숫자를 예측하는 방법이에요 / 앞 강좌의 kNN이 / 사과일까 귤일까처럼 종류를 골랐다면, / 선형 회귀는 몇 개 팔릴까처럼 / 숫자를 맞혀요
- 화면: 가운데 그래프(점과 초록 직선) 한 장 → 화면을 둘로 나눠 왼쪽 「kNN · 종류」(사과·귤 그림과 「귤」), 오른쪽 「선형 회귀 · 숫자」(직선 그래프와 「약 80개」)
- 움직임: "가장 잘 지나는 직선을"에서 직선이 점들 사이로 내려앉음, "새 값의"에서 새 x 위치에 세로 점선이 올라가 직선과 만남, "kNN이"에서 화면 분할

### L04 · 자전거 기록 (쇼츠 S1)

- 의도: 거의 일직선인 점 네 개를 보여 주고 처음 보는 값(1시간 30분)을 맞혀 보게 한다
- 읽기: 자전거를 탈 때마다 탄 시간과 간 거리를 적어 뒀어요. [삼십 분|30분]에 [칠 점 오 킬로미터|7.5km], [한 시간|1시간]에 [십오 점 오 킬로미터|15.5km]를 갔어요. [두 시간|2시간]에는 [이십구 점 오 킬로미터|29.5km], [두 시간 삼십 분|2시간 30분]에는 [삼십팔 킬로미터|38km]였어요. 그럼 [한 시간 삼십 분|1시간 30분]을 타면 몇 킬로미터를 갈까요?
- 자막: 자전거를 탈 때마다 / 탄 시간과 간 거리를 적어 뒀어요 / 30분에 7.5km, / 1시간에 15.5km를 갔어요 / 2시간에는 29.5km, / 2시간 30분에는 38km였어요 / 그럼 1시간 30분을 타면 / 몇 킬로미터를 갈까요?
- 화면: 원고 l1_bike처럼 가로축 「탄 시간(시간)」 0~3, 세로축 「간 거리(km)」 0~40 그래프. 기록 네 개가 파란 점으로 찍히고 점마다 값 이름표. 1.5시간 자리에 물음표가 달린 세로 점선
- 움직임: 기록을 말할 때마다 그 점이 찍힘, "1시간 30분을"에서 1.5 자리 세로 점선과 물음표, 3초 카운트다운
- 멈춤: 2초

### L05 · 직선을 긋고 읽어요 (쇼츠 S1)

- 의도: 점들을 잇는 직선 하나로 처음 보는 값을 읽어 내는 것이 선형 회귀의 핵심 동작임을 보여 준다
- 읽기: 약 [이십이 점 육 킬로미터|22.6km]예요. 점들이 거의 한 줄로 늘어서 있어서, 점들을 잇는 직선을 긋고 [한 시간 반|1시간 반] 자리를 읽으면 돼요. 이 직선은 [한 시간|1시간]에 [십오 킬로미터|15km]씩 간다는 규칙과 같아요. 점이 거의 일직선이면, 직선 하나로 처음 보는 값도 쉽게 예측할 수 있어요.
- 자막: 약 22.6km예요 / 점들이 거의 한 줄로 늘어서 있어서, / 점들을 잇는 직선을 긋고 / 1시간 반 자리를 읽으면 돼요 / 이 직선은 1시간에 15km씩 / 간다는 규칙과 같아요 / 점이 거의 일직선이면, / 직선 하나로 처음 보는 값도 / 쉽게 예측할 수 있어요
- 화면: L04 그래프에 초록 직선이 그어지고, 1.5 자리 세로 점선이 직선과 만나는 곳에서 가로 점선이 세로축으로 가 「약 22.6km」. 직선 옆에 「1시간에 15km씩」 이름표
- 움직임: "직선을 긋고"에서 직선이 왼쪽 아래에서 오른쪽 위로 그어짐, "자리를 읽으면"에서 점선이 꺾여 22.6에 닿음, "15km씩"에서 직선 위 한 칸(1시간 → 15km) 계단 표시

### L06 · 아이스크림은 한 줄로 안 서요

- 의도: 현실 데이터는 모든 점을 지나는 직선이 없다는 것을 보여 주고 「가장 그럴듯한 직선」을 고르는 기준이 필요하다는 질문을 남긴다
- 읽기: 이번엔 아이스크림 가게예요. 닷새 동안 기온과 판매량을 적었어요. 더울수록 많이 팔리는 건 보이는데, 점들이 한 줄로 딱 맞지는 않아요. [이십 도|20°C]와 [이십이 도|22°C]에는 똑같이 [쉰다섯 개|55개]가 팔렸거든요. 이번엔 모든 점을 지나는 직선이 없어요. 그래서 가장 그럴듯한 직선을 고르는 기준이 필요해요.
- 자막: 이번엔 아이스크림 가게예요 / 닷새 동안 기온과 판매량을 적었어요 / 더울수록 많이 팔리는 건 보이는데, / 점들이 한 줄로 딱 맞지는 않아요 / 20°C와 22°C에는 / 똑같이 55개가 팔렸거든요 / 이번엔 모든 점을 지나는 직선이 없어요 / 그래서 가장 그럴듯한 직선을 / 고르는 기준이 필요해요
- 화면: 원고 l2_icecream처럼 가로축 「기온(°C)」 18~32, 세로축 「판매량(개)」 그래프에 점 다섯 개. 20°C·22°C 두 점이 같은 높이(55개)에 나란히 강조. 자 모양 막대가 점들 위에서 이리저리 기울어 보다가 멈추지 못함
- 움직임: "닷새 동안"에서 점이 하나씩 찍힘, "똑같이 55개가"에서 두 점에 가로 점선, "모든 점을 지나는 직선이 없어요"에서 자 막대가 세 번 기울며 매번 몇 점을 놓침, "기준이"에서 물음표

### L07 · 분류와 회귀

- 의도: 인공지능이 맞히는 답을 종류(분류)와 숫자(회귀) 둘로 나눠 이번 강좌의 위치를 잡아 준다
- 읽기: 인공지능이 맞히는 답은 크게 두 가지예요. 사과인지 귤인지처럼 종류를 맞히는 건 분류예요. 판매량이나 거리처럼 숫자를 맞히는 건 회귀예요. 정답이 붙은 데이터로 배우니, 선형 회귀도 지도 학습이에요.
- 자막: 인공지능이 맞히는 답은 크게 두 가지예요 / 사과인지 귤인지처럼 / 종류를 맞히는 건 분류예요 / 판매량이나 거리처럼 / 숫자를 맞히는 건 회귀예요 / 정답이 붙은 데이터로 배우니, / 선형 회귀도 지도 학습이에요
- 화면: 원고 3장 표를 두 칸 카드로. 왼쪽 「분류 · 종류를 맞혀요 · kNN · 답: 귤」, 오른쪽 「회귀 · 숫자를 맞혀요 · 선형 회귀 · 답: 약 80개」. 아래에 「지도 학습 = 정답이 붙은 데이터로 배워요」 띠
- 움직임: "분류예요"에서 왼쪽 카드, "회귀예요"에서 오른쪽 카드, "지도 학습이에요"에서 아래 띠가 두 카드를 감쌈

### L08 · 직선은 두 가지로 정해져요

- 의도: 직선의 두 요소(기울기, 절편)를 자전거 직선 위에서 눈으로 보여 준다
- 읽기: 직선은 두 가지만 알면 정해져요. 얼마나 기울었는지와 어디서 출발하는지예요. 자전거 직선은 [한 시간|1시간] 더 탈 때마다 [십오 킬로미터|15km]씩 더 가요. 이게 기울기예요. 그리고 [영 시간|0시간] 탔을 때의 거리는 거의 영이에요. 이게 절편이에요. 안 타면 영 킬로미터라는 상식과 맞죠.
- 자막: 직선은 두 가지만 알면 정해져요 / 얼마나 기울었는지와 / 어디서 출발하는지예요 / 자전거 직선은 1시간 더 탈 때마다 / 15km씩 더 가요 / 이게 기울기예요 / 그리고 0시간 탔을 때의 거리는 / 거의 영이에요 / 이게 절편이에요 / 안 타면 영 킬로미터라는 / 상식과 맞죠
- 화면: 원고 l4b_bike_slope처럼 자전거 직선 그래프. 직선 위 계단(가로 1시간, 세로 15km)에 「기울기 = 1시간마다 15km」, 세로축과 만나는 점에 동그라미 「절편 ≈ 0km」
- 움직임: "얼마나 기울었는지"에서 직선이 살짝 흔들림, "15km씩"에서 계단이 직선을 따라 두 번 반복, "0시간 탔을 때"에서 직선이 세로축 쪽으로 이어져 동그라미

### L09 · 아이스크림 직선 읽기

- 의도: 같은 두 요소를 아이스크림 직선에 적용하고, 그 직선으로 27°C를 읽어 처음 질문(L01)에 답한다
- 읽기: 아이스크림 직선도 볼게요. 기온이 [일 도|1°C] 오를 때마다 [네 개|4개]씩 더 팔려요. 이게 기울기예요. 절편은 [영 도|0°C]일 때 값으로 [마이너스 이십팔|-28]이에요. 실제로 [마이너스 스물여덟 개|-28개]가 팔릴 수는 없죠. 이건 뒤에서 다시 볼게요. 이 직선으로 [이십칠 도|27°C]를 읽으면, 약 [여든 개|80개]가 팔린다고 예측해요. 처음 질문의 답이에요.
- 자막: 아이스크림 직선도 볼게요 / 기온이 1°C 오를 때마다 4개씩 더 팔려요 / 이게 기울기예요 / 절편은 0°C일 때 값으로 -28이에요 / 실제로 -28개가 팔릴 수는 없죠 / 이건 뒤에서 다시 볼게요 / 이 직선으로 27°C를 읽으면, / 약 80개가 팔린다고 예측해요 / 처음 질문의 답이에요

### L11 · 오차를 제곱해서 더해요

- 의도: 오차를 그냥 더하면 +와 -가 지워진다는 문제와, 제곱해서 더하는 해결책(최소제곱법)을 보여 준다
- 읽기: 막대 길이를 그냥 더하면 문제가 생겨요. 직선보다 위에 있는 점은 플러스, 아래에 있는 점은 마이너스라서 서로 지워지거든요. 그래서 오차를 제곱해서 모두 양수로 만든 뒤 더해요. 이 값이 오차 제곱합이에요. 오차 제곱합이 가장 작은 직선이 가장 잘 맞는 직선이고, 이렇게 찾는 방법을 최소제곱법이라고 해요. 그림에서는 [에이|A]와 [씨|C]가 [백오십이|152], [비|B]가 [팔십사|84]라서 [비|B]가 가장 잘 맞아요.
- 자막: 막대 길이를 그냥 더하면 문제가 생겨요 / 직선보다 위에 있는 점은 플러스, / 아래에 있는 점은 마이너스라서 / 서로 지워지거든요 / 그래서 오차를 제곱해서 / 모두 양수로 만든 뒤 더해요 / 이 값이 오차 제곱합이에요 / 오차 제곱합이 가장 작은 직선이 / 가장 잘 맞는 직선이고, / 이렇게 찾는 방법을 최소제곱법이라고 해요 / 그림에서는 A와 C가 152, / B가 84라서 B가 가장 잘 맞아요

## 쇼츠 전용 장면

### S1E · 쇼츠 S1 마무리

- 의도: 점이 한 줄로 서지 않을 때는 어디에 그을지라는 다음 궁금증을 남기고 강의로 넘긴다
- 읽기: 그럼 점들이 한 줄로 서지 않으면, 직선은 어디에 그어야 할까요? 선형 회귀 강의에서 확인해 보세요.
- 자막: 그럼 점들이 한 줄로 서지 않으면, / 직선은 어디에 그어야 할까요? / 선형 회귀 강의에서 / 확인해 보세요
- 화면: L06의 흩어진 아이스크림 점 다섯 개와, 그 위에서 기울기를 못 정하는 자 막대, 물음표
- 움직임: "한 줄로 서지 않으면"에서 점이 흩어짐, "어디에"에서 자 막대가 흔들림

### S2A · 쇼츠 S2 도입

- 의도: 쇼츠만 보는 사람에게 「더울수록 더 팔리는 직선」을 먼저 보여 준다
- 읽기: 선형 회귀는 점들 사이에 직선을 그어 숫자를 예측해요. 아이스크림은 기온이 [일 도|1°C] 오를 때마다 [네 개|4개]씩 더 팔리는 직선이 나왔어요.
- 자막: 선형 회귀는 점들 사이에 직선을 그어 / 숫자를 예측해요 / 아이스크림은 기온이 1°C 오를 때마다 / 4개씩 더 팔리는 직선이 나왔어요
- 화면: 아이스크림 점과 초록 직선, 계단 「1°C마다 4개」
- 움직임: "직선을 그어"에서 직선, "4개씩"에서 계단

### S2E · 쇼츠 S2 마무리

- 의도: 튀는 점 말고 다른 함정도 있다는 궁금증으로 강의로 넘긴다
- 읽기: 그럼 직선을 믿으면 안 되는 경우는 또 무엇이 있을까요? 선형 회귀 강의에서 확인해 보세요.
- 자막: 그럼 직선을 믿으면 안 되는 경우는 / 또 무엇이 있을까요? / 선형 회귀 강의에서 / 확인해 보세요
- 화면: 함정 네 칸 중 「튀는 점」만 열리고 나머지 세 칸은 물음표로 가린 카드
- 움직임: "또 무엇이"에서 물음표 세 칸이 흔들림

### S3A · 쇼츠 S3 도입

- 의도: 쇼츠만 보는 사람에게 선형 회귀가 「함께 움직이는 두 숫자」 사이에 직선을 긋는 방법이라는 것을 먼저 알려 준다
- 읽기: 선형 회귀는 함께 움직이는 두 숫자 사이에 직선을 그어서, 한쪽 숫자로 다른 쪽 숫자를 예측해요. 그런데 직선이 잘 맞으면 원인도 찾은 걸까요?
- 자막: 선형 회귀는 함께 움직이는 두 숫자 사이에 / 직선을 그어서, / 한쪽 숫자로 다른 쪽 숫자를 예측해요 / 그런데 직선이 잘 맞으면 / 원인도 찾은 걸까요?
- 화면: 점 그래프와 초록 직선, 가로축 숫자에서 세로축 숫자로 이어지는 점선 화살표, 끝에 물음표
- 움직임: "직선을 그어서"에서 직선, "예측해요"에서 점선 화살표, "원인도"에서 물음표

### S3E · 쇼츠 S3 마무리

- 의도: 원인 착각 말고 회귀가 숫자를 예측하는 방법 자체로 궁금증을 돌려 강의로 넘긴다
- 읽기: 그럼 회귀는 함께 움직이는 관계를, 어떻게 직선 하나로 찾아낼까요? 선형 회귀 강의에서 확인해 보세요.
- 자막: 그럼 회귀는 함께 움직이는 관계를, / 어떻게 직선 하나로 찾아낼까요? / 선형 회귀 강의에서 / 확인해 보세요
- 화면: 흩어진 점들 위로 직선이 이리저리 돌다가 멈추는 그림, 물음표
- 움직임: "어떻게 직선 하나로"에서 직선이 돌기 시작함, "찾아낼까요"에서 멈춤과 물음표
