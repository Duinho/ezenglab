# 냉장고와 에어컨 영상 장면표

## 공통 규칙

- **읽기** 줄은 타입캐스트에 넣는 문장이에요. 자막은 읽기 줄에서 아래 표기 규칙으로 바꿔 만들어요.
- 숫자는 소리를 한글로 직접 적어요(예: `[이십사 도|24°C]`).
- `{천천히: …}` 부분은 따로 만들어 천천히 읽어요. 핵심 용어(증발, 압축, 팽창, 냉매, 서미스터, 히트펌프)를 처음 소개할 때 한 번만 써요.
- **자막** 줄은 모든 장면에 써요. 주어·목적어와 서술어, 용어와 조사가 갈라지지 않게 뜻 단위로 끊어요.
- 생활 기기 시리즈 규칙: 분해 장면 없이 기기 그림 위에 센서·액추에이터·원리를 이름표(캡션)로 띄워요. "보통 이런 방식"으로 말하고 단정하지 않아요.
- 색은 원고 그림을 따라요. 차가움·열 빼앗기 파랑, 뜨거움·열 버리기 빨강, 센서 청록, 액추에이터 빨강 계열, 압축 보라, 팽창 주황.
- 글꼴은 페이퍼로지만 써요. 페이퍼로지에 없는 기호(❄, ℃, ✕, 이모지)는 쓰지 않아요. 온도는 「°C」로 적어요.
- 숫자와 사실은 원고에 있는 것만 써요. 「24°C」는 원고 5-3의 예시, 「4°C 켜기 · 2°C 쉬기」는 원고 그림 c5의 설명용 숫자예요(말로 읽지 않음).

### 표기 규칙 (읽기 → 자막)

- `[읽는 소리|자막 글자]`: 그 자리만 따로 바꿔요.

## 장면

### L01 · 여는 질문

- 읽기: 냉장고 옆면에 손을 대 보면 따뜻할 때가 있어요. 차갑게 하는 기계인데, 옆면은 왜 따뜻할까요? 오늘은 냉장고와 에어컨이 어떻게 차갑게 만드는지 알아볼게요.
- 자막: 냉장고 옆면에 손을 대 보면 / 따뜻할 때가 있어요 / 차갑게 하는 기계인데, / 옆면은 왜 따뜻할까요? / 오늘은 냉장고와 에어컨이 / 어떻게 차갑게 만드는지 알아볼게요
- 화면: 냉장고 그림, 옆면에 손과 빨간 열 물결, 물음표 → 강좌 제목 「냉장고와 에어컨」
- 움직임: "냉장고"에서 냉장고, "따뜻할"에서 옆면 열 물결, "왜"에서 물음표, "오늘은"에서 제목

### L02 · 채널 인사 (공통 인트로)

- 읽기: 안녕하세요, [눈바공 연구소|눈바공 연구소] [바닥 연구소장입니다.|바닥 연구소장입니다.]
- 화면: 공통 인트로
- 움직임: 공통 인트로(tools/video/intro.js)
- 앞멈춤: 0.5초
- 멈춤: 1초

### L03 · 먼저 한 줄로

- 읽기: 먼저 한 줄로 정리할게요. 냉장고와 에어컨은 차가움을 만드는 기계가 아니에요. 안쪽의 열을 바깥으로 옮기는 기계예요.
- 자막: 먼저 한 줄로 정리할게요 / 냉장고와 에어컨은 / 차가움을 만드는 기계가 아니에요 / 안쪽의 열을 바깥으로 / 옮기는 기계예요
- 화면: 큰 글 「차가움을 만드는」에 가로줄 → 「열을 <b>옮기는</b> 기계」, 안쪽(파랑) → 바깥쪽(빨강) 화살표
- 움직임: "아니에요"에서 가로줄, "옮기는"에서 새 문장과 화살표

### L04 · 냉장고와 에어컨이 열을 옮기는 곳 (쇼츠 S1)

- 읽기: 냉장고는 냉장고 안의 열을 꺼내 방으로 버려요. 에어컨은 방 안의 열을 꺼내 집 밖으로 버려요.
- 자막: 냉장고는 냉장고 안의 열을 꺼내 / 방으로 버려요 / 에어컨은 방 안의 열을 꺼내 / 집 밖으로 버려요
- 화면: 왼쪽 냉장고(안 파랑) → 「열」 화살표 → 방, 오른쪽 벽걸이 에어컨 → 벽 → 실외기(원고 c1)
- 움직임: "냉장고는"에서 왼쪽, "방으로"에서 화살표, "에어컨은"에서 오른쪽, "집 밖으로"에서 화살표

### L05 · 그래서 옆면이 따뜻해요 (쇼츠 S1)

- 읽기: 열을 빼앗긴 쪽은 차가워지고, 열을 받은 쪽은 따뜻해져요. 냉장고 옆면이 따뜻한 것도, 에어컨 실외기에서 뜨거운 바람이 나오는 것도 이 때문이에요.
- 자막: 열을 빼앗긴 쪽은 차가워지고, / 열을 받은 쪽은 따뜻해져요 / 냉장고 옆면이 따뜻한 것도, / 에어컨 실외기에서 / 뜨거운 바람이 나오는 것도 / 이 때문이에요
- 화면: L04 그림 유지, 「차가워짐」(파랑) 「따뜻해짐」(빨강) 이름표, 냉장고 옆면·실외기 열 물결
- 움직임: "차가워지고"에서 파랑 이름표, "따뜻해져요"에서 빨강 이름표, "옆면이"·"실외기에서"에서 해당 열 물결이 반짝

### L06 · 손 소독제를 바르면

- 읽기: 열을 옮기는 방법은 생활 속 세 가지 현상을 이어 붙인 거예요. 손 소독제를 바르면 손이 시원해져요. 알코올이 날아가면서 손의 열을 가져가기 때문이에요. 액체가 기체로 바뀌는 걸 {천천히: 증발}이라고 하는데, 증발할 때 주변의 열을 빼앗아요.
- 자막: 열을 옮기는 방법은 / 생활 속 세 가지 현상을 이어 붙인 거예요 / 손 소독제를 바르면 손이 시원해져요 / 알코올이 날아가면서 / 손의 열을 가져가기 때문이에요 / 액체가 기체로 바뀌는 걸 / 증발이라고 하는데, / 증발할 때 주변의 열을 빼앗아요
- 화면: 세 칸(알코올·펌프·스프레이) 중 첫 칸, 손등과 알코올 방울, 김이 위로 → 「증발 · 시원해져요」(파랑)
- 움직임: "세 가지"에서 세 칸 윤곽(회색), "손"에서 첫 칸 그림, "날아가면서"에서 김, "증발"에서 이름표

### L07 · 자전거 펌프를 누르면

- 읽기: 자전거 펌프를 계속 누르면 펌프 아래쪽이 따뜻해져요. 공기를 좁은 곳에 꾹 눌러 담으면 온도가 올라가요. 이걸 {천천히: 압축}이라고 해요.
- 자막: 자전거 펌프를 계속 누르면 / 펌프 아래쪽이 따뜻해져요 / 공기를 좁은 곳에 꾹 눌러 담으면 / 온도가 올라가요 / 이걸 압축이라고 해요
- 화면: 둘째 칸, 펌프 손잡이가 내려가고 아래쪽이 빨개짐 → 「압축 · 뜨거워져요」(빨강)
- 움직임: "펌프를"에서 그림, "누르면"부터 손잡이 오르내림, "따뜻해져요"에서 아래쪽 색, "압축"에서 이름표

### L08 · 스프레이를 뿌리면

- 읽기: 뿌리는 파스를 오래 누르고 있으면 캔이 차가워져요. 캔 안의 압력이 낮아지면서 액체가 기체로 바뀌고, 캔의 열을 빼앗아요. 이렇게 압력을 확 낮추는 걸 {천천히: 팽창}이라고 해요.
- 자막: 뿌리는 파스를 오래 누르고 있으면 / 캔이 차가워져요 / 캔 안의 압력이 낮아지면서 / 액체가 기체로 바뀌고, / 캔의 열을 빼앗아요 / 이렇게 압력을 확 낮추는 걸 / 팽창이라고 해요
- 화면: 셋째 칸, 스프레이 캔과 뿜어 나오는 점선 → 「팽창 · 차가워져요」(파랑)
- 움직임: "파스를"에서 그림, "누르고"부터 점선, "압력이"에서 캔 색이 파래짐, "팽창"에서 이름표

### L09 · 세 가지에서 찾은 규칙

- 읽기: 증발하면 차가워지고, 압축하면 뜨거워지고, 압력을 낮추면 차가워져요. 냉장고와 에어컨은 이 세 가지를 한 바퀴로 이어서 계속 돌려요.
- 자막: 증발하면 차가워지고, / 압축하면 뜨거워지고, / 압력을 낮추면 차가워져요 / 냉장고와 에어컨은 이 세 가지를 / 한 바퀴로 이어서 계속 돌려요
- 화면: 세 칸이 작아지며 한 줄로 → 「증발 ↓ · 압축 ↑ · 팽창 ↓」 → 세 칸을 잇는 둥근 화살표
- 움직임: 말하는 칸이 차례로 튀어 오름, "한 바퀴로"에서 둥근 화살표

### L10 · 관 속을 도는 냉매

- 읽기: 냉장고와 에어컨 안에는 관이 한 바퀴로 이어져 있어요. 그 안을 {천천히: 냉매}라는 물질이 돌아요. 냉매는 아주 낮은 온도에서도 쉽게 증발해요.
- 자막: 냉장고와 에어컨 안에는 / 관이 한 바퀴로 이어져 있어요 / 그 안을 냉매라는 물질이 돌아요 / 냉매는 아주 낮은 온도에서도 / 쉽게 증발해요
- 화면: 네모난 관 고리(원고 c3, 아직 색 없음), 냉매 알갱이가 관을 따라 돎, 「냉매」 이름표
- 움직임: "관이"에서 고리가 그려짐, "냉매라는"에서 알갱이와 이름표

### L11 · ① 증발

- 읽기: 첫째는 증발이에요. 차갑고 압력이 낮은 냉매가 안쪽 관을 지나며 증발해요. 알코올처럼 주변의 열을 빼앗아서, 냉장고 안이 차가워져요.
- 자막: 첫째는 증발이에요 / 차갑고 압력이 낮은 냉매가 / 안쪽 관을 지나며 증발해요 / 알코올처럼 주변의 열을 빼앗아서, / 냉장고 안이 차가워져요
- 화면: 고리 왼쪽 관이 파랗게, 「① 증발 · 열을 빼앗아요」, 「안쪽」 이름표
- 움직임: "첫째는"에서 왼쪽 관 색, "열을"에서 바깥 열 화살표가 관으로 빨려 듦

### L12 · ② 압축

- 읽기: 둘째는 압축이에요. 열을 머금은 냉매를 압축기가 꾹 눌러 담아요. 펌프처럼 냉매가 뜨거워져요.
- 자막: 둘째는 압축이에요 / 열을 머금은 냉매를 / 압축기가 꾹 눌러 담아요 / 펌프처럼 냉매가 뜨거워져요
- 화면: 위쪽 압축기 상자가 나타나 꿈틀, 「② 압축 · 뜨거워져요」
- 움직임: "압축기가"에서 상자, "뜨거워져요"에서 오른쪽 관이 빨개지기 시작

### L13 · ③ 열 버리기

- 읽기: 셋째는 열 버리기예요. 뜨거워진 냉매가 바깥쪽 관을 지나며 주변 공기에 열을 버려요. 열을 잃은 냉매는 다시 액체가 돼요.
- 자막: 셋째는 열 버리기예요 / 뜨거워진 냉매가 바깥쪽 관을 지나며 / 주변 공기에 열을 버려요 / 열을 잃은 냉매는 / 다시 액체가 돼요
- 화면: 오른쪽 관 빨강, 열 물결이 바깥으로, 「③ 열 버리기 · 바깥에 내놓아요」, 「바깥쪽」 이름표
- 움직임: "셋째는"에서 이름표, "버려요"에서 열 물결

### L14 · ④ 팽창

- 읽기: 넷째는 팽창이에요. 액체 냉매가 아주 가는 관을 지나며 압력이 확 떨어지고 차가워져요. 그리고 다시 첫째 단계로 돌아가요.
- 자막: 넷째는 팽창이에요 / 액체 냉매가 아주 가는 관을 지나며 / 압력이 확 떨어지고 차가워져요 / 그리고 다시 첫째 단계로 돌아가요
- 화면: 아래쪽 가는 관(주황), 「④ 팽창 · 다시 차가워져요」, 알갱이가 왼쪽으로 돌아감
- 움직임: "넷째는"에서 가는 관, "다시"에서 알갱이가 한 바퀴를 마저 돎

### L15 · 한 바퀴를 한 줄로

- 읽기: 냉매는 닳지 않고 이 길을 계속 돌아요. 전기는 냉매를 압축하고, 팬을 돌리는 데 써요.
- 자막: 냉매는 닳지 않고 / 이 길을 계속 돌아요 / 전기는 냉매를 압축하고, / 팬을 돌리는 데 써요
- 화면: 완성된 고리(원고 c3), 알갱이가 계속 돎, 「전기 → 압축기·팬」 칩
- 움직임: "계속"에서 알갱이 속도 오름, "전기는"에서 칩

### L16 · 냉장고 부품 지도

- 읽기: 이제 냉장고를 들여다볼게요. 판단은 냉장고 안의 제어 기판이 해요. 온도 센서가 안쪽 온도를 재고, 압축기와 팬, 전등, 성에를 녹이는 히터가 움직여요.
- 자막: 이제 냉장고를 들여다볼게요 / 판단은 냉장고 안의 제어 기판이 해요 / 온도 센서가 안쪽 온도를 재고, / 압축기와 팬, 전등, / 성에를 녹이는 히터가 움직여요
- 화면: 냉장고 단면(원고 c4), 이름표가 하나씩: 「제어 기판 · 판단」 「온도 센서 · 온도를 재요」(청록) 「압축기」 「팬」 「전등」 「히터」(빨강)
- 움직임: 부품 이름을 말할 때 그 이름표와 연결선이 나타남

### L17 · 차갑게 유지하기

- 읽기: 온도 센서는 보통 온도에 따라 저항이 바뀌는 {천천히: 서미스터}를 써요. 제어 기판은 설정 온도보다 따뜻해지면 압축기를 돌리고, 충분히 차가워지면 쉬게 해요.
- 자막: 온도 센서는 보통 / 온도에 따라 저항이 바뀌는 / 서미스터를 써요 / 제어 기판은 설정 온도보다 / 따뜻해지면 압축기를 돌리고, / 충분히 차가워지면 쉬게 해요
- 화면: 세 칸 「① 알아채기 · 온도 센서」 「② 판단하기 · 제어 기판」 「③ 움직이기 · 압축기 모터」 + 아래 온도 그래프(원고 c5, 「4°C → 켜기」 「2°C → 쉬기」 「숫자는 설명용」)
