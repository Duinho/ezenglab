# 전압·전류·저항 영상 장면표

## 공통 규칙

- **읽기** 줄은 타입캐스트에 넣는 문장이에요. 자막은 읽기 줄에서 아래 표기 규칙으로 바꿔 만들어요.
- 숫자는 소리를 한글로 직접 적어요(예: `[일 점 오 볼트|1.5V]`).
- `{천천히: …}` 부분은 따로 만들어 천천히 읽어요. 핵심 용어를 처음 소개할 때 한 번만 써요. L01에서 강좌 이름을 말할 때는 천천히 읽지 않아요.
- **자막** 줄이 있으면 자막을 그 줄의 ` / ` 자리에서 끊어요.
- **멈춤** 줄이 있으면 그 장면 음성 뒤에 그만큼 말없이 화면만 보여 줘요.
- 색은 원고 그림을 따라요. 전압 빨강, 전류 파랑, 저항 주황.
- 글꼴은 페이퍼로지만 써요. 페이퍼로지에 없는 기호(Ω, ρ, ⎓)는 화면에서는 도형으로 그리고, 자막에서는 「옴」 「로」처럼 한글로 적어요.
- 숫자와 사실은 원고에 있는 것만 써요. 충전기 「5V 3A」는 원고 9-1의 예시 표기예요.

### 표기 규칙 (읽기 → 자막)

- `[읽는 소리|자막 글자]`: 그 자리만 따로 바꿔요.

## 장면

### L01 · 여는 질문

- 읽기: 휴대폰 충전기 뒷면에는 [오 볼트|5V], [삼 암페어|3A] 같은 숫자가 적혀 있어요. 이 숫자들은 무슨 뜻일까요? 오늘은 전기를 이해하는 세 단어, 전압, 전류, 저항을 알아볼게요.
- 자막: 휴대폰 충전기 뒷면에는 / 5V, 3A 같은 숫자가 적혀 있어요 / 이 숫자들은 무슨 뜻일까요? / 오늘은 전기를 이해하는 세 단어, / 전압, 전류, 저항을 알아볼게요
- 화면: 충전기 그림(뒷면 표기 「5V ⎓ 3A」), 숫자에 물음표 → 강좌 제목 「전압·전류·저항」
- 움직임: "충전기"에서 충전기, "숫자"에서 5V·3A가 반짝, "무슨 뜻"에서 물음표, "세 단어"에서 제목

### L02 · 채널 인사 (공통 인트로)

- 읽기: 안녕하세요, [눈바공 연구소|눈바공 연구소] [바닥 연구소장입니다.|바닥 연구소장입니다.]
- 화면: 공통 인트로
- 움직임: 공통 인트로(tools/video/intro.js)
- 앞멈춤: 0.5초
- 멈춤: 1초

### L03 · 세 단어 한 줄씩

- 읽기: 세 단어를 먼저 한 줄씩 볼게요. 전압은 전기를 미는 힘이에요. 전류는 실제로 흐르는 전기의 양이에요. 저항은 그 흐름을 막는 정도예요. 처음에는 셋이 헷갈리는 게 당연해요.
- 화면: 세 칸 카드 「전압 · 미는 힘」(빨강) 「전류 · 흐르는 양」(파랑) 「저항 · 막는 정도」(주황)
- 움직임: 낱말을 말할 때 카드가 차례로, "헷갈리는"에서 세 카드가 살짝 흔들림

### L04 · 빨대로 마실 때 (쇼츠 S1)

- 읽기: 빨대로 음료를 마실 때를 떠올려 볼게요. 세 가지가 함께 움직여요. 하나는 입으로 끌어올리는 힘이에요. 또 하나는 빨대로 올라오는 음료의 양이고요. 마지막은 빨대가 얼마나 좁은지예요.
- 화면: 컵과 빨대 그림(원고 v1), 번호 ① 끌어올리는 힘(위 화살표) ② 올라오는 음료의 양(빨대 속 화살표) ③ 빨대가 좁은 정도(빨대 폭 화살표)
- 움직임: "빨대로"에서 컵·빨대, "끌어올리는"에서 ①, "음료의 양"에서 ②, "좁은지"에서 ③

### L05 · 전기에서는? (쇼츠 S1)

- 읽기: 전기에서는 각각 무엇에 해당할까요?
- 화면: ①②③ 옆에 빈 칸 「전압 ?」 「전류 ?」 「저항 ?」, 3초 카운트다운
- 움직임: 빈 칸이 나타나고 카운트다운
- 멈춤: 2초

### L06 · 정답 (쇼츠 S1)

- 읽기: 끌어올리는 힘은 전압이에요. 올라오는 음료의 양은 전류고요. 빨대가 좁은 정도는 저항이에요.
- 화면: ①→전압(빨강), ②→전류(파랑), ③→저항(주황) 줄이 이어짐
- 움직임: "전압"·"전류"·"저항"에서 각 칸이 채워짐

### L07 · 이미 몸으로 알아요

- 읽기: 세게 빨수록 많이 올라오고, 빨대가 좁을수록 적게 올라온다는 건 이미 몸으로 알고 있어요. 이 감각을 그대로 들고 세 단어를 하나씩 자세히 볼게요.
- 자막: 세게 빨수록 많이 올라오고, / 빨대가 좁을수록 적게 올라온다는 건 / 이미 몸으로 알고 있어요 / 이 감각을 그대로 들고 / 세 단어를 하나씩 자세히 볼게요
- 화면: 빨대 둘 비교 「세게 빨면 → 많이」 「좁은 빨대 → 적게」
- 움직임: "세게"에서 왼쪽, "좁을수록"에서 오른쪽

### L08 · 전기가 흐른다는 것

- 읽기: 전선 속에는 전기를 실어 나르는 아주 작은 알갱이가 있어요. 이걸 전하라고 해요. 이 알갱이들이 한쪽으로 움직이는 것을 전기가 흐른다고 해요.
- 화면: 전선 단면 속 파란 알갱이들, 「전하」 이름표, 알갱이가 한쪽으로 움직임 + 「흐르는 방향 →」
- 움직임: "알갱이"에서 점, "전하"에서 이름표, "움직이는"부터 점이 오른쪽으로 흘러감

### L09 · 전류 (쇼츠 S3 앞부분과 같은 그림)

- 읽기: {천천히: 전류}는 전선의 한 지점을 [일 초|1초] 동안 지나가는 전기의 양이에요. 같은 시간에 많이 지나가면 전류가 크고, 적게 지나가면 전류가 작아요.
- 화면: 전선 두 줄(원고 v2), 가운데 점선 「여기를 1초에 몇 개 지나갈까?」, 위는 점 적게 「전류가 작다」, 아래는 점 많이 「전류가 크다」
- 움직임: 점이 계속 흐름, "한 지점"에서 점선, "많이"에서 아래 줄, "적게"에서 위 줄

### L10 · 전류의 단위

- 읽기: 전류의 단위는 [암페어|A(암페어)]예요. 식에서는 [아이|I]로 써요. 작은 회로에서는 [밀리암페어|mA(밀리암페어)]를 많이 쓰는데, [일 암페어|1A]가 [천 밀리암페어|1,000mA]예요. 아두이노 우노는 핀 하나에 [이십 밀리암페어|20mA] 정도를 권장해요.
- 자막: 전류의 단위는 A(암페어)예요 / 식에서는 I로 써요 / 작은 회로에서는 / mA(밀리암페어)를 많이 쓰는데, / 1A가 1,000mA예요 / 아두이노 우노는 핀 하나에 / 20mA 정도를 권장해요
- 화면: 전류 카드(파랑) 「단위 A(암페어)」 「기호 I」 → 「1A = 1,000mA」 → 아두이노 핀 「20mA 정도」
- 움직임: "암페어"에서 단위, "아이"에서 기호, "천"에서 환산, "아두이노"에서 핀 그림

### L11 · 전압은 높이 차이 (쇼츠 S2)

- 읽기: {천천히: 전압}은 높이 차이와 비슷해요. 공이 높은 곳에서 낮은 곳으로 굴러가듯, 전기도 전압이 높은 쪽에서 낮은 쪽으로 흘러요. 높이 차가 클수록 공이 세게 굴러가는 것처럼, 전압이 클수록 전기를 더 세게 밀어요.
- 자막: 전압은 높이 차이와 비슷해요 / 공이 높은 곳에서 낮은 곳으로 굴러가듯, / 전기도 전압이 높은 쪽에서 낮은 쪽으로 흘러요 / 높이 차가 클수록 공이 세게 굴러가는 것처럼, / 전압이 클수록 전기를 더 세게 밀어요
- 화면: 비탈 두 개(원고 v3), 왼쪽 낮은 비탈 「전압이 낮다」, 오른쪽 높은 비탈 「전압이 높다」, 위 +·아래 −, 공이 굴러감
- 움직임: "높은 곳에서"에서 왼쪽 공이 굴러감, "클수록"에서 오른쪽 비탈과 공이 더 빠르게

### L12 · 전압은 두 지점 사이 (쇼츠 S2)

- 읽기: 꼭 기억할 점이 있어요. 전압은 항상 두 지점 사이의 차이예요. 이 건전지는 [일 점 오 볼트|1.5V]라는 말은 [플러스극|+극]과 [마이너스극|−극] 사이 높이 차가 [일 점 오 볼트|1.5V]라는 뜻이에요. 단위는 [볼트|V(볼트)], 식에 쓰는 기호도 [브이|V]예요.
- 자막: 꼭 기억할 점이 있어요 / 전압은 항상 두 지점 사이의 차이예요 / 이 건전지는 1.5V라는 말은 / +극과 −극 사이 높이 차가 / 1.5V라는 뜻이에요 / 단위는 V(볼트), 식에 쓰는 기호도 V예요
- 화면: 건전지 그림 +극·−극, 두 극 사이 세로 화살표 「1.5V」, 전압 카드(빨강) 「단위 V(볼트)」 「기호 V」
- 움직임: "두 지점"에서 +·− 표시, "높이 차가"에서 화살표, "볼트"에서 카드

### L13 · 주변에서 만나는 전압

- 읽기: 주변에서 만나는 전압을 비교해 볼게요. [에이에이|AA] 건전지는 [일 점 오 볼트|1.5V]예요. 아두이노의 [삼 점 삼 볼트|3.3V] 핀은 [삼 점 삼 볼트|3.3V]예요. [유에스비|USB]와 아두이노 우노의 [오 볼트|5V] 핀은 [오 볼트|5V]예요. 우리나라 가정용 콘센트는 [이백이십 볼트|220V]예요. 콘센트 전기는 실습 대상이 아니에요.
- 자막: 주변에서 만나는 전압을 비교해 볼게요 / AA 건전지는 1.5V예요 / 아두이노의 3.3V 핀은 3.3V예요 / USB와 아두이노 우노의 5V 핀은 5V예요 / 우리나라 가정용 콘센트는 220V예요 / 콘센트 전기는 실습 대상이 아니에요
- 화면: 가로 막대그래프(원고 v4, 눈금이 한 칸 갈 때마다 10배) AA 건전지 1.5V / 아두이노 3.3V 핀 / USB·아두이노 5V 핀 / 가정용 콘센트 220V, 마지막에 콘센트 막대에 「실습 대상 아님」
- 움직임: 이름을 말할 때 막대가 차오름, "실습 대상이 아니에요"에서 경고 표시

### L14 · 저항

- 읽기: {천천히: 저항}은 전기의 흐름을 방해하는 정도예요. 빨대가 좁고 길수록 마시기 힘든 것과 같아요.
- 화면: 저항 카드(주황) 「흐름을 막는 정도」, 옆에 짧고 넓은 빨대와 좁고 긴 빨대
- 움직임: "방해하는"에서 카드, "좁고 길수록"에서 빨대 비교

### L15 · 저항을 바꾸는 세 가지 (쇼츠 S3)

- 읽기: 저항은 세 가지에 따라 달라져요. 먼저 길이예요. 같은 선이라도 길수록 저항이 커져요. 다음은 굵기예요. 가늘수록 저항이 커져요. 마지막은 재질이에요. 구리처럼 전기가 잘 통하는 재료는 저항이 작고, 고무처럼 잘 안 통하는 재료는 저항이 아주 커요.
- 자막: 저항은 세 가지에 따라 달라져요 / 먼저 길이예요 / 같은 선이라도 길수록 저항이 커져요 / 다음은 굵기예요 / 가늘수록 저항이 커져요 / 마지막은 재질이에요 / 구리처럼 전기가 잘 통하는 재료는 저항이 작고, / 고무처럼 잘 안 통하는 재료는 저항이 아주 커요
- 화면: 세 줄 표(원고 v5) 길이(짧은 선·긴 선), 굵기(굵은 선·가는 선), 재질(구리·고무), 각 줄 「저항 작음」 「저항 큼」
- 움직임: "길이"·"굵기"·"재질"에서 각 줄, "커져요"·"작고"에서 이름표

### L16 · 식으로 쓰면

- 읽기: 식으로 쓰면 이렇게 돼요. [알은 로 곱하기 엘 나누기 에이예요|R = 로 × L ÷ A]. 로는 재질마다 정해진 값, [엘|L]은 길이, [에이|A]는 단면적이에요. 지금은 길면 커지고 굵으면 작아진다는 것만 기억해도 충분해요.
- 자막: 식으로 쓰면 이렇게 돼요 / R = 로 × L ÷ A / 로는 재질마다 정해진 값, / L은 길이, A는 단면적이에요 / 지금은 길면 커지고 굵으면 작아진다는 것만 / 기억해도 충분해요
- 화면: 큰 식 「R = ρ × L ÷ A」, 아래 이름표 ρ 재질 값 · L 길이 · A 단면적, 마지막에 「길면 ↑ 굵으면 ↓」
- 움직임: "알은"에서 식, 이름을 말할 때 각 기호가 반응, "길면"에서 마지막 줄

### L17 · 저항의 단위와 쓰임

- 읽기: 저항의 단위는 [옴|옴]이고, 식에서는 [알|R]로 써요. [천 옴|1,000옴]은 [일 킬로옴|1킬로옴]이에요. 전자 회로에서는 흐름을 일부러 줄이려고 저항 부품을 넣어요. [엘이디|LED]에 저항을 같이 다는 이유도 이거예요.
- 자막: 저항의 단위는 옴이고, 식에서는 R로 써요 / 1,000옴은 1킬로옴이에요 / 전자 회로에서는 흐름을 일부러 줄이려고 / 저항 부품을 넣어요 / LED에 저항을 같이 다는 이유도 이거예요
- 화면: 저항 카드(주황) 「단위 옴」 「기호 R」 → 「1kΩ = 1,000Ω」 → LED와 저항을 이은 그림
- 움직임: "옴"에서 단위, "알로"에서 기호, "천 옴"에서 환산, "엘이디"에서 그림

### L18 · 세 단어 한눈에

- 읽기: 세 단어를 한눈에 정리해 볼게요. 전압은 전기를 미는 힘이고, 단위는 [볼트|V(볼트)]예요. 전류는 [일 초|1초] 동안 흐르는 전기의 양이고, 단위는 [암페어|A(암페어)]예요. 저항은 흐름을 막는 정도이고, 단위는 [옴|옴]이에요.
