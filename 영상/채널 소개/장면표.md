# 채널 소개 영상 장면표

## 공통 규칙

- **읽기** 줄은 타입캐스트에 넣는 문장이에요. 자막은 읽기 줄에서 아래 표기 규칙으로 바꿔 만들어요.
- **자막** 줄이 있으면 그 줄의 ` / ` 자리에서 끊어요.
- 수식은 실제 강좌에 나온 식만 써요(옴의 법칙, 전압 분배, 선형 회귀, 로지스틱 회귀, kNN 거리).
- 열매 사진은 「인공지능 첫걸음」 img/에서 가져왔어요. 롤케이크는 「가변저항」 2-2 그림(10칸, 칼 자리 3·5·8칸 → 30%·50%·80%)을 코드로 다시 그려요.

## 장면

### L01 · 공감

- 읽기: 공학 공부, 수식부터 나오면 막막하죠?
- 화면: 실제 강좌 수식 여섯 개가 하나씩 쏟아짐(V = IR, 전압 분배, ŷ = wx + b, 로지스틱, kNN 거리, 키르히호프), 가운데 「?」
- 움직임: 문장 시작부터 수식이 차례로, "막막하죠"에서 물음표

### L02 · 눈높이를 바닥까지

- 읽기: 그래서 눈높이를 바닥까지 낮췄어요.
- 화면: 수식들이 아래로 떨어져 흐려지고, 바닥 선 위에 쉬운 그림(열매, 롤케이크)이 남음
- 움직임: "바닥까지"에서 수식이 떨어짐, "낮췄어요"에서 그림 등장

### L03 · 채널 인사 (공통 인트로)

- 읽기: 안녕하세요, [눈바공 연구소|눈바공 연구소] [바닥 연구소장입니다.|바닥 연구소장입니다.]
- 화면: 공통 인트로
- 움직임: 공통 인트로(tools/video/intro.js)
- 앞멈춤: 0.5초
- 멈춤: 0.6초

### L04 · 쉬운 예시 먼저

- 읽기: 여기서는 어려운 개념을 쉬운 예시로 먼저 보여 드려요.
- 화면: 「어려운 개념」(흐린 수식 카드) → 「쉬운 예시」(초록 카드)로 바뀌는 화살표
- 움직임: "어려운 개념"에서 왼쪽 카드, "쉬운 예시"에서 화살표와 오른쪽 카드

### L05 · 예시 1 — 인공지능

- 읽기: 예를 들어 인공지능은 처음 보는 열매 이름을 맞혀 보면서 배워요.
- 화면: 「인공지능 첫걸음」 명찰, 처음 보는 열매 사진 + 물음표 → 「별꼭지 열매?」 이름표
- 움직임: "인공지능"에서 명찰, "열매"에서 사진, "맞혀"에서 이름표

### L06 · 예시 2 — 가변저항

- 읽기: 가변저항은 롤케이크를 자르는 칼 자리를 옮겨 보면서 배우고요.
- 화면: 「가변저항」 명찰, 10칸 롤케이크, 칼이 3칸 → 5칸 → 8칸으로 옮겨지며 「내 몫 30%·50%·80%」
- 움직임: "가변저항"에서 명찰, "롤케이크"에서 케이크, "칼"에서 칼, "옮겨"부터 칼이 움직임

### L07 · 한 단계씩

- 읽기: 예시로 감을 잡은 다음, 원리와 계산은 한 단계씩 따라가요.
- 화면: 계단 세 칸 「예시 → 원리 → 계산」, 진행 점이 한 칸씩 올라감
- 움직임: "예시"·"원리"·"계산"에서 각 칸

### L08 · 다루는 과목

- 읽기: 지금은 인공지능, 전자공학, 전자 부품을 다루고 있고, 꾸준히 새 강의가 올라와요.
- 화면: 과목 카드 3장(인공지능·전자공학·전자 부품) → 「꾸준히 새 강의」 칩
- 움직임: 과목 이름을 말할 때 카드, "꾸준히"에서 칩

### L09 · 보는 순서

- 읽기: 쇼츠로 짧게 맛보고, 전체 강의는 재생목록 순서대로 봐요. 계산 과정은 블로그에서 이어서 볼 수 있어요.
- 자막: 쇼츠로 짧게 맛보고, / 전체 강의는 재생목록 순서대로 봐요 / 계산 과정은 블로그에서 이어서 볼 수 있어요
- 화면: 「쇼츠 · 짧게 맛보기」 → 「롱폼 · 재생목록 순서대로」 → 「블로그 · 계산 과정」 세 상자와 화살표
- 움직임: "쇼츠"·"전체"·"계산"에서 각 상자, 화살표는 앞 상자에서 다음 상자로

### L10 · 마무리

- 읽기: 바닥부터 같이 올라가 볼까요? 구독하고 첫 강의부터 시작해 보세요.
- 화면: 「눈바공 연구소」 로고 + 「바닥 연구소장」 명패, 구독 버튼, 「첫 강의부터 시작해 보세요」
- 움직임: "바닥부터"에서 로고, "구독하고"에서 구독 버튼 눌림, "첫 강의부터"에서 마지막 문구
- 멈춤: 1초
