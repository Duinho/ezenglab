# 전자 부품 지도 영상 장면표

## 공통 규칙

- **읽기** 줄은 타입캐스트에 넣는 문장이에요. 자막은 읽기 줄에서 아래 표기 규칙으로 바꿔 만들어요.
- 숫자는 소리를 한글로 직접 적어요(예: `[오 볼트|5V]`). 값·이름표는 한자어, 개수는 고유어(다섯 갈래, 세 단계, 여덟 개)로 읽어요.
- 천천히 읽기(`{천천히: …}`)는 쓰지 않아요(2026-11-11 팀장님 결정). 용어도 보통 속도로 읽어요.
- **자막** 줄은 모든 장면에 써요. 주어·목적어와 서술어, 용어와 조사가 갈라지지 않게 뜻 단위로 끊어요.
- **의도** 줄은 그 장면이 무엇을 보여 주려는지 한 줄로 적은 거예요. 화면을 만들 때 이 한 줄이 전달되는지 먼저 봐요(읽지 않음, 화면에 쓰지 않음).
- 지도의 다섯 칸 색을 영상 끝까지 똑같이 써요(원고 그림 p3_map). 센서 청록, 제어 장치 초록(#14936a), 액추에이터·출력 장치 빨강 계열, 회로 부품 보라, 전원 주황. 부품이 어느 칸인지 말할 때 그 칸 색 테두리를 두르면 돼요.
- 부품 그림은 원고 그림(p1~p11)의 모양을 따라 SVG로 다시 그려요. 사진은 쓰지 않아요.
- 글꼴은 페이퍼로지만 써요. 저항 단위는 화면·자막 모두 Ω·kΩ이고 도형으로 그려요(영상_제작_기준 「자막」). 페이퍼로지에 없는 기호(✕, ⚠, 이모지)는 쓰지 않아요. 화살표는 SVG 도형으로 그려요.
- 숫자와 사실은 원고에 있는 것만 써요. 「센서 1kΩ·10kΩ」「기준 400」은 원고 4-1이 계산을 보여 주려고 정한 예시라서, 화면 구석에 「예시 값」 이름표를 붙여요.
- 액추에이터와 출력 장치는 원고 5장처럼 「액추에이터·출력 장치」 한 칸으로 묶어요. 움직임(모터)은 액추에이터, 빛·소리(LED, 부저)는 출력 장치라고 말해요.

### 표기 규칙 (읽기 → 자막)

- `[읽는 소리|자막 글자]`: 그 자리만 따로 바꿔요.

## 장면

### L01 · 여는 질문

- 의도: 누구나 본 장면(저절로 켜지는 가로등)으로 궁금증을 만들고 제목으로 넘긴다
- 읽기: 해가 지면 아무도 스위치를 누르지 않았는데 가로등이 켜져요. 가로등은 어떻게 어두워진 걸 알았을까요? 오늘은 전자 기기 속 부품들을 한 장의 지도로 정리해 볼게요.
- 자막: 해가 지면 아무도 스위치를 / 누르지 않았는데 가로등이 켜져요 / 가로등은 어떻게 / 어두워진 걸 알았을까요? / 오늘은 전자 기기 속 부품들을 / 한 장의 지도로 정리해 볼게요
- 화면: 노을 진 길가의 가로등(꺼짐) → 하늘이 어두워지며 전등이 켜짐, 물음표 → 강좌 제목 「전자 부품 지도」
- 움직임: "해가 지면"에서 하늘 색이 어두워짐, "켜져요"에서 전등이 켜짐, "어떻게"에서 물음표, "지도로"에서 제목

### L02 · 채널 인사 (공통 인트로)

- 읽기: 안녕하세요, [눈바공 연구소|눈바공 연구소] [바닥 연구소장입니다.|바닥 연구소장입니다.]
- 자막: 안녕하세요, 눈바공 연구소 / 바닥 연구소장입니다
- 화면: 공통 인트로
- 움직임: 공통 인트로(tools/video/intro.js)

- 멈춤: 1초

### L03 · 먼저 한 줄로

- 의도: 오늘 결론(부품은 하는 일로 다섯 갈래)을 먼저 보여 주고, 지도의 다섯 칸을 처음 등장시킨다
- 읽기: 먼저 한 줄로 정리할게요. 전자 기기 속 부품은 하는 일에 따라 다섯 갈래로 나눌 수 있어요. 알아채는 센서, 판단하는 제어 장치, 일을 하는 액추에이터와 출력 장치예요. 여기에 이들을 이어 주는 회로 부품, 에너지를 주는 전원이 더해져요.
- 자막: 먼저 한 줄로 정리할게요 / 전자 기기 속 부품은 하는 일에 따라 / 다섯 갈래로 나눌 수 있어요 / 알아채는 센서, 판단하는 제어 장치, / 일을 하는 액추에이터와 출력 장치예요 / 여기에 이들을 이어 주는 회로 부품, / 에너지를 주는 전원이 더해져요
- 화면: 가로로 늘어선 다섯 칸(센서 청록 · 제어 장치 초록 · 액추에이터·출력 장치 빨강 · 회로 부품 보라 · 전원 주황), 칸마다 이름과 한 단어(알아채요 · 판단해요 · 일해요 · 이어 줘요 · 에너지)
- 움직임: "다섯 갈래로"에서 빈 칸 다섯 개 윤곽(회색), 이름을 말할 때마다 그 칸에 색과 이름이 들어옴

### L04 · 가로등의 세 단계 (쇼츠 S1)

- 의도: 가로등이 하는 일을 알아채기 → 판단하기 → 켜기 세 단계로 쪼갠다
- 읽기: 가로등이 하는 일을 세 단계로 나눠 볼게요. 먼저 빛의 양을 재는 조도 센서가 어두워진 걸 알아채요. 다음으로 [엠씨유|MCU]가 센서 값을 보고, 기준보다 어두우니 켜자고 판단해요. 마지막으로 전등이 켜져요.
- 자막: 가로등이 하는 일을 / 세 단계로 나눠 볼게요 / 먼저 빛의 양을 재는 조도 센서가 / 어두워진 걸 알아채요 / 다음으로 MCU가 센서 값을 보고, / 기준보다 어두우니 켜자고 판단해요 / 마지막으로 전등이 켜져요
- 화면: 원고 p1_streetlight처럼 가로등 그림 옆에 세 칸 「① 알아채기 · 조도 센서」(청록) → 「② 판단하기 · MCU」(초록) → 「③ 켜기 · 전등」(빨강), 칸 사이 화살표
- 움직임: "조도 센서가"에서 ① 칸과 가로등 위 센서 반짝, "MCU가"에서 ② 칸과 화살표, "켜자고"에서 ② 칸에 말풍선 「켜자」, "전등이"에서 ③ 칸과 전등 켜짐

### L05 · 자동문도 똑같아요 (쇼츠 S1)

- 의도: 전혀 다른 기기(자동문)도 같은 세 단계라는 것을 같은 틀에 넣어 보여 준다
- 읽기: 마트 자동문도 똑같이 나눠 볼까요? [피아이알|PIR] 센서가 사람이 다가온 걸 알아채요. [엠씨유|MCU]가 사람이 왔으니 열자고 판단해요. 그러면 모터가 돌아 문을 양옆으로 밀어 열어요.
- 자막: 마트 자동문도 똑같이 나눠 볼까요? / PIR 센서가 사람이 다가온 걸 알아채요 / MCU가 사람이 왔으니 열자고 판단해요 / 그러면 모터가 돌아 / 문을 양옆으로 밀어 열어요
- 화면: L04의 세 칸 틀을 그대로 두고 그림만 자동문으로 바뀜(원고 p2_door_pir), 「① PIR 센서」 → 「② MCU」 → 「③ 모터」, 문이 양옆으로 열림
- 움직임: "자동문도"에서 그림 교체, "PIR 센서가"에서 ① 칸과 사람 그림, "MCU가"에서 ②, "모터가"에서 ③과 모터 회전, "열어요"에서 문이 열림

### L06 · 두 예시에서 찾은 규칙 (쇼츠 S1)

- 의도: 두 예시를 겹쳐 입력 → 처리 → 출력이라는 공통 흐름을 이름 붙인다
- 읽기: 가로등과 자동문은 하는 일이 전혀 다른데, 흐름은 똑같아요. 무언가가 바깥 변화를 알아채고, 무언가가 판단하고, 무언가가 실제로 일을 해요. 이걸 입력, 처리, 출력이라고 불러요. 거의 모든 전자 기기가 이 흐름으로 움직여요.
- 자막: 가로등과 자동문은 하는 일이 / 전혀 다른데, 흐름은 똑같아요 / 무언가가 바깥 변화를 알아채고, / 무언가가 판단하고, / 무언가가 실제로 일을 해요 / 이걸 입력, 처리, 출력이라고 불러요 / 거의 모든 전자 기기가 / 이 흐름으로 움직여요
- 화면: 가로등 줄과 자동문 줄을 위아래로 겹쳐 놓고, 세로 칸 머리에 「입력」(청록) 「처리」(초록) 「출력」(빨강)
- 움직임: "똑같아요"에서 두 줄이 위아래로 맞춰짐, "입력"·"처리"·"출력"에서 칸 머리가 차례로 나타남

### L07 · 사람 몸으로 보는 지도

- 의도: 입력·처리·출력을 사람 몸(눈·뇌·팔다리)에 겹쳐 기억하기 쉽게 만든다
- 읽기: 이 흐름은 사람이 움직이는 방식과 닮았어요. 눈과 귀와 피부로 알아채고, 뇌가 판단하고, 팔다리와 목소리로 일을 하죠. 전자 부품으로 바꾸면 센서가 눈, [엠씨유|MCU]가 뇌, 액추에이터와 출력 장치가 팔다리와 목소리예요.
- 자막: 이 흐름은 사람이 움직이는 방식과 닮았어요 / 눈과 귀와 피부로 알아채고, / 뇌가 판단하고, / 팔다리와 목소리로 일을 하죠 / 전자 부품으로 바꾸면 / 센서가 눈, MCU가 뇌, / 액추에이터와 출력 장치가 / 팔다리와 목소리예요
- 화면: 원고 p3_map처럼 가운데 사람 몸 그림, 눈·뇌·팔다리에 선을 그어 오른쪽에 「센서」(청록) 「MCU」(초록) 「액추에이터·출력 장치」(빨강) 이름표
- 움직임: "눈과 귀와 피부로"에서 눈·귀·피부 반짝, "뇌가"에서 뇌, "팔다리와"에서 팔다리, "센서가 눈"부터 선과 이름표가 하나씩 이어짐

### L08 · 혈관과 심장도 있어요

- 의도: 지도의 나머지 두 칸(회로 부품, 전원)을 몸의 혈관·신경·관절과 심장·음식에 붙여 다섯 칸 지도를 완성한다
- 읽기: 사람 몸에는 혈관과 신경도 있어요. 겉으로 잘 보이지 않지만 모든 곳을 이어 주죠. 전자 기기에서는 저항이나 캐패시터 같은 회로 부품이 이 일을 해요. 그리고 심장과 음식이 에너지를 주듯, 전원이 모든 부품에 에너지를 줘요.
- 자막: 사람 몸에는 혈관과 신경도 있어요 / 겉으로 잘 보이지 않지만 / 모든 곳을 이어 주죠 / 전자 기기에서는 저항이나 캐패시터 같은 / 회로 부품이 이 일을 해요 / 그리고 심장과 음식이 에너지를 주듯, / 전원이 모든 부품에 에너지를 줘요
- 화면: L07 그림에 혈관·신경 선(보라)과 심장(주황)이 더해짐, 「회로 부품」(보라) 「전원」(주황) 이름표, 다섯 칸 지도 완성
- 움직임: "혈관과 신경도"에서 보라 선이 몸 전체로 번짐, "회로 부품이"에서 보라 이름표, "심장과 음식이"에서 심장 박동, "전원이"에서 주황 이름표

### L09 · MCU는 작은 컴퓨터 칩

- 의도: 처음 나온 낯선 말 MCU를 한 번 풀어 주고, 이 갈래에서는 「판단하는 칸」으로만 본다고 선을 긋는다
- 읽기: 여기서 [엠씨유|MCU]는 작은 컴퓨터 칩이에요. 아두이노 보드에 올라가 있는 칩이 바로 [엠씨유|MCU]예요. 이 갈래에서는 [엠씨유|MCU]를 판단하는 칸으로만 보고, 자세한 내용은 따로 다룰게요.
- 자막: 여기서 MCU는 작은 컴퓨터 칩이에요 / 아두이노 보드에 올라가 있는 칩이 / 바로 MCU예요 / 이 갈래에서는 MCU를 / 판단하는 칸으로만 보고, / 자세한 내용은 따로 다룰게요
- 화면: 아두이노 보드 그림(단순화), 가운데 칩에 동그라미와 「MCU · Microcontroller Unit」 이름표, 지도 「제어 장치」 칸(초록)으로 칩이 들어감
- 움직임: "작은 컴퓨터 칩"에서 칩 확대, "아두이노 보드에"에서 보드 전체, "판단하는 칸으로만"에서 칩이 초록 칸으로 이동

### L10 · 센서: 바깥 변화를 전기 신호로

- 의도: 센서의 정의를 보여 주고, 센서마다 「무엇이 바뀌는지」가 다르다는 것을 표로 보여 준다
- 읽기: 이제 칸을 하나씩 볼게요. 센서는 빛, 온도, 거리 같은 바깥 변화를 전기 신호로 바꾸는 부품이에요. 조도 센서와 온도 센서는 저항이 바뀌어요. 버튼은 회로가 이어지거나 끊겨요. 초음파 센서는 소리가 돌아오는 시간으로 거리를 알려 줘요.
- 자막: 이제 칸을 하나씩 볼게요 / 센서는 빛, 온도, 거리 같은 바깥 변화를 / 전기 신호로 바꾸는 부품이에요 / 조도 센서와 온도 센서는 저항이 바뀌어요 / 버튼은 회로가 이어지거나 끊겨요 / 초음파 센서는 소리가 돌아오는 시간으로 / 거리를 알려 줘요
- 화면: 지도에서 「센서」 칸(청록)이 커짐 → 원고 4장 표를 줄인 카드 네 장(조도 센서 · 온도 센서 · 버튼 · 초음파 센서), 카드마다 그림과 「무엇이 바뀌나」 한 줄

- 의도: 아두이노와 모터를 모르는 쇼츠 시청자에게 무엇이 무엇을 움직이는지 먼저 알려 준다
- 읽기: 아두이노 같은 작은 컴퓨터 칩은 판단을 맡고, 모터는 실제로 움직이는 일을 맡아요.
- 자막: 아두이노 같은 작은 컴퓨터 칩은 판단을 맡고, / 모터는 실제로 움직이는 일을 맡아요
- 화면: 왼쪽 아두이노 보드 「판단」(초록), 오른쪽 모터 「움직임」(빨강)
- 움직임: "작은 컴퓨터 칩은"에서 보드, "모터는"에서 모터 회전

### S3E · 쇼츠 S3 마무리

- 의도: 모터를 켜 주는 「밸브」 부품에 궁금증을 남기고 강의로 넘긴다
- 읽기: 그럼 모터를 켜 주는 이 부품은, 부품 지도의 어느 칸에 들어갈까요? 전자 부품 지도 강의에서 확인해 보세요.
- 자막: 그럼 모터를 켜 주는 이 부품은, / 부품 지도의 어느 칸에 들어갈까요? / 전자 부품 지도 강의에서 / 확인해 보세요
- 화면: L14 끝 그림(MCU → 트랜지스터 상자 → 모터)에서 트랜지스터 상자에 물음표, 옆에 다섯 칸 지도(작게)
- 움직임: "모터를 켜 주는"에서 굵은 선과 모터 회전, "어느 칸에"에서 다섯 칸 지도(작게)와 물음표
