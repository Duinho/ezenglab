# 전압 분배 영상 장면표

## 공통 규칙

- **읽기** 줄은 타입캐스트에 넣는 문장이에요. 자막은 읽기 줄에서 표기 규칙으로 바꿔 만들어요.
- 숫자는 소리를 한글로 직접 적어요(예: `[구 볼트|9V]`). 저항 이름은 `[알 일|R1]`, `[알 이|R2]`로 읽어요.
- `{천천히: …}`는 핵심 용어를 처음 소개할 때 한 번만 써요. L01에서 강좌 이름을 말할 때는 천천히 읽지 않아요.
- 모든 장면에 **자막** 줄이 있어요. 자막은 ` / ` 자리에서만 끊어요.
- **멈춤** 줄이 있으면 그 장면 음성 뒤에 그만큼 말없이 화면만 보여 줘요.
- 색은 전자공학 110~130과 같아요. 전압 빨강, 전류 파랑, 저항 주황. 출력 점은 초록(#14936a). 장면 코드와 스타일은 `영상/전자공학 130 키르히호프의 법칙/`(없으면 120, 110)을 바탕으로 해요.
- 페이퍼로지에 없는 기호(✕, ⚠)는 쓰지 않아요. 저항 단위는 화면·자막 모두 기호로 보여요(팀장님 2026-11-12·11-14): 장면표에는 「10킬로옴」「100옴」으로 적고, scenes.js의 ohmNotation과 render.py 자막이 「10kΩ」「100Ω」(Ω는 도형)으로 바꿔요. 「옴의 법칙」처럼 이름인 옴은 그대로예요. 「×」「÷」「+」「−」「=」「:」는 써도 돼요. 아래 첨자는 「V출력」「V전원」처럼 작은 글자로 붙여 써요.
- 숫자와 사실은 원고에 있는 것만 써요.

### 표기 규칙 (읽기 → 자막)

- `[읽는 소리|자막 글자]`: 그 자리만 따로 바꿔요.

### L05 · 전기로 바꾸면 (쇼츠 S1)

- 읽기: 여기서 규칙을 찾을 수 있어요. 전체 양은 정해져 있고, 각자 몫의 비율대로 나눠 가져요. 몫이 클수록 더 많이 가져가요. 전기로 바꾸면 전체 양은 전원 전압이고, 몫은 저항이에요. 그래서 저항이 큰 쪽이 전압을 더 많이 가져가요.
- 자막: 여기서 규칙을 찾을 수 있어요 / 전체 양은 정해져 있고, / 각자 몫의 비율대로 나눠 가져요 / 몫이 클수록 더 많이 가져가요 / 전기로 바꾸면 전체 양은 전원 전압이고, / 몫은 저항이에요 / 그래서 저항이 큰 쪽이 / 전압을 더 많이 가져가요
- 화면: 두 열 표 「피자 | 전기」 줄 「한 판 | 전원 전압」(빨강) 「몫 | 저항」(주황) 「큰 몫 → 많이 | 큰 저항 → 전압 많이」

### L06 · 회로로 보기 (쇼츠 S1)

- 자막: 지난 영상의 회로를 세로로 세워 볼게요 / 위는 9V, 아래는 0V예요 / 그 사이에 1킬로옴과 2킬로옴이 / 한 줄로 이어져 있어요 / 1킬로옴이 3V, 2킬로옴이 6V를 가져가요 / 저항이 1 : 2니 전압도 1 : 2예요
- 화면: 원고 d3_basic 구성. 세로 회로 위 「9V」, 아래 「0V(GND)」, 위 저항 「1킬로옴」, 아래 저항 「2킬로옴」(주황, 아래 저항이 두 배 길게). 저항 오른쪽에 「3V」「6V」(빨강)

### L07 · 출력 전압

- 읽기: 위 저항을 [알 일|R1], 아래 저항을 [알 이|R2]라고 부를게요. 두 저항 사이 점과 아래 사이에는 [알 이|R2]가 가져간 [육 볼트|6V]가 걸려요. 이 가운데 점의 전압을 {천천히: 출력 전압}이라고 해요. 전압 분배에서는 대부분 이 값을 구하거나 이용해요.
- 자막: 위 저항을 R1, 아래 저항을 R2라고 부를게요 / 두 저항 사이 점과 아래 사이에는 / R2가 가져간 6V가 걸려요 / 이 가운데 점의 전압을 출력 전압이라고 해요 / 전압 분배에서는 대부분 / 이 값을 구하거나 이용해요
- 화면: L06 회로에 「R1」「R2」 이름표, 두 저항 사이 점(초록 원)에서 오른쪽으로 짧은 선 「출력」, 출력 점과 GND 사이 세로 화살표 「6V」
- 움직임: "알 일"·"알 이"에서 이름표, "사이 점과"에서 초록 점, "육 볼트가"에서 화살표, "출력 전압"에서 「출력」 꼬리표가 반짝

### L08 · 식이 나오는 과정 1

- 읽기: 식은 외우지 않아도 돼요. 앞에서 배운 세 법칙을 이어 붙이면 나와요. 갈림길이 없으니 두 저항에 같은 전류가 흘러요. 전류 법칙이에요. 그 전류는 전체 전압 나누기 전체 저항이에요. 옴의 법칙이죠.
- 자막: 식은 외우지 않아도 돼요 / 앞에서 배운 세 법칙을 이어 붙이면 나와요 / 갈림길이 없으니 / 두 저항에 같은 전류가 흘러요 / 전류 법칙이에요 / 그 전류는 전체 전압 나누기 전체 저항이에요 / 옴의 법칙이죠
- 화면: 왼쪽 세로 회로(작게), 오른쪽 단계 카드 「1 같은 전류가 흐름 · 전류 법칙」 「2 I = V전원 ÷ (R1 + R2) · 옴의 법칙」
- 움직임: "세 법칙을"에서 칩 셋(옴·KCL·KVL), "같은 전류가"에서 회로에 파란 점이 한 줄로 흐르고 1번 카드, "전체 전압 나누기"에서 2번 카드

### L09 · 식이 나오는 과정 2

- 읽기: [알 이|R2]가 가져가는 전압은 전류 곱하기 [알 이|R2]예요. 둘을 합치면 전압 분배 식이 돼요. 출력 전압은 전원 전압 곱하기, [알 이|R2] 나누기 [알 일 더하기 알 이|R1 + R2]예요. 말로 풀면 전원 전압 곱하기 내 몫의 비율이에요. 피자 한 판에 내 몫의 비율을 곱하는 것과 같은 모양이에요.
- 자막: R2가 가져가는 전압은 전류 곱하기 R2예요 / 둘을 합치면 전압 분배 식이 돼요 / 출력 전압은 전원 전압 곱하기, / R2 나누기 R1 + R2예요 / 말로 풀면 전원 전압 곱하기 / 내 몫의 비율이에요 / 피자 한 판에 내 몫의 비율을 / 곱하는 것과 같은 모양이에요
- 화면: 3번 카드 「3 V출력 = I × R2 · 옴의 법칙」 → 가운데 큰 식 「V출력 = V전원 × R2 ÷ (R1 + R2)」(V 빨강, R 주황) → 아래 말풀이 「전원 전압 × 내 몫의 비율」, 작은 피자 아이콘
- 움직임: "전류 곱하기"에서 3번 카드, "합치면"에서 2번과 3번 카드가 큰 식으로 합쳐짐, "말로 풀면"에서 말풀이, "피자 한 판에"에서 피자 아이콘

### L10 · 비율로 쓰기

- 읽기: 같은 내용을 비율로도 쓸 수 있어요. 두 저항에는 같은 전류가 흐르니까, 두 저항의 전압 비는 저항 비와 같아요.
- 자막: 같은 내용을 비율로도 쓸 수 있어요 / 두 저항에는 같은 전류가 흐르니까, / 두 저항의 전압 비는 저항 비와 같아요
- 화면: 「V1 : V2 = R1 : R2」, 아래 L06 숫자 「3V : 6V = 1킬로옴 : 2킬로옴」
- 움직임: "비율로도"에서 식, "같아요"에서 숫자 줄

### L11 · 저항을 알 때: 전압 구하기

- 읽기: 저항 두 개와 전원 전압을 알면 출력 전압을 바로 구할 수 있어요. [오 볼트|5V]에 [십 킬로옴|10킬로옴] 두 개면 [오 곱하기 십 나누기 이십|5 × 10 ÷ 20], [이 점 오 볼트|2.5V]예요. [오 볼트|5V]에 [알 일|R1]이 [이 킬로옴|2킬로옴], [알 이|R2]가 [삼 킬로옴|3킬로옴]이면 [오 곱하기 삼 나누기 오|5 × 3 ÷ 5], [삼 볼트|3V]예요. 같은 저항 두 개를 이으면 언제나 절반이 나와요.
- 자막: 저항 두 개와 전원 전압을 알면 / 출력 전압을 바로 구할 수 있어요 / 5V에 10킬로옴 두 개면 / 5 × 10 ÷ 20, 2.5V예요 / 5V에 R1이 2킬로옴, R2가 3킬로옴이면 / 5 × 3 ÷ 5, 3V예요 / 같은 저항 두 개를 이으면 / 언제나 절반이 나와요
- 화면: 원고 d4_bars_v2 구성. 가로 막대 두 줄. 줄마다 왼쪽 끝 전원 전압, R1 칸·R2 칸(길이가 저항 비율), 두 칸 경계에 초록 출력 점과 출력 값. 줄 1 「5V | 10킬로옴 | 10킬로옴 → 2.5V」, 줄 2 「5V | 2킬로옴 | 3킬로옴 → 3V」. 옆에 계산 줄
- 움직임: "십 킬로옴 두 개면"에서 줄 1, "이 점 오"에서 출력 점과 값, "이 킬로옴"에서 줄 2, "삼 볼트예요"에서 값, "언제나 절반"에서 줄 1의 출력 점이 가운데에 있음을 표시하는 점선

### L12 · 전압을 알 때: 저항 고르기

- 자막: 모터처럼 전류를 많이 쓰는 부품을 달면 / 전압이 더 크게 흔들리고, / 저항이 뜨거워질 수도 있어요 / 전압 분배는 센서 값을 읽거나 / 신호 전압을 맞출 때 써요 / 부품에 전원을 줄 때는 / 전압 레귤레이터를 써요
- 화면: 모터 아이콘 + 흔들리는 전압 선, 저항에 빨간 열 물결. 아래 두 칩 「전압 분배 → 센서·신호」 「전원 → 전압 레귤레이터」
- 움직임: "모터처럼"에서 아이콘, "흔들리고"에서 선이 흔들림, "뜨거워질"에서 열 물결, "센서 값을"에서 첫 칩, "레귤레이터"에서 둘째 칩

### L25 · 저항 크기와 전압 높이기

- 읽기: 비율이 같아도 저항 크기가 중요해요. [백 옴|100옴] 두 개로 [오 볼트|5V]를 나누면 [이십오 밀리암페어|25mA]가 늘 흘러요. [십 킬로옴|10킬로옴] 두 개면 [영 점 이오 밀리암페어|0.25mA]만 흘러요. 그래서 센서나 신호용에는 보통 킬로옴 단위 저항을 써요. 그리고 전압 분배의 출력은 항상 전원 전압보다 낮아요. 전압을 높이는 데는 쓸 수 없어요.
- 자막: 비율이 같아도 저항 크기가 중요해요 / 100옴 두 개로 5V를 나누면 / 25mA가 늘 흘러요 / 10킬로옴 두 개면 0.25mA만 흘러요 / 그래서 센서나 신호용에는 / 보통 킬로옴 단위 저항을 써요 / 그리고 전압 분배의 출력은 / 항상 전원 전압보다 낮아요 / 전압을 높이는 데는 쓸 수 없어요
- 화면: 두 줄 「100옴 + 100옴 → 25mA」(굵은 파란 화살표) 「10킬로옴 + 10킬로옴 → 0.25mA」(가는 파란 화살표). 아래 「출력 < 전원 전압」 「3.3V → 5V 불가」(회색 줄 긋기 도형)
- 움직임: "백 옴"에서 첫 줄, "십 킬로옴 두 개면"에서 둘째 줄, "항상"에서 아래 첫 칩, "높이는 데는"에서 둘째 칩

### L26 · 한눈에 정리

- 읽기: 한눈에 정리해 볼게요. 직렬 저항은 전압을 저항 비율대로 나눠 가져요. 출력 전압은 전원 전압 곱하기 [알 이|R2] 나누기 [알 일 더하기 알 이|R1 + R2]예요. 많은 센서는 저항이 바뀌고, 전압 분배가 그 변화를 전압 변화로 바꿔요. 아두이노는 그 전압을 숫자로 읽어요. 전원용으로는 쓰지 않고, 전압을 높일 수도 없어요.
- 자막: 한눈에 정리해 볼게요 / 직렬 저항은 전압을 저항 비율대로 나눠 가져요 / 출력 전압은 전원 전압 곱하기 / R2 나누기 R1 + R2예요 / 많은 센서는 저항이 바뀌고, / 전압 분배가 그 변화를 전압 변화로 바꿔요 / 아두이노는 그 전압을 숫자로 읽어요 / 전원용으로는 쓰지 않고, / 전압을 높일 수도 없어요
- 화면: 요약 상자(원고 11장) 위에 「V출력 = V전원 × R2 ÷ (R1 + R2)」, 아래 네 줄 「저항 비율대로 나눔」 「센서 저항 변화 → 전압 변화」 「아두이노 우노: 0~1023」 「전원용 아님 · 높이기 불가」
- 움직임: 말하는 순서대로 한 줄씩

### L27 · 퀴즈

- 읽기: 마지막으로 퀴즈 하나예요. [십 볼트|10V] 전원에 [알 일|R1]은 [삼 킬로옴|3킬로옴], [알 이|R2]는 [이 킬로옴|2킬로옴]이에요. 출력 전압은 몇 볼트일까요?
- 자막: 마지막으로 퀴즈 하나예요 / 10V 전원에 / R1은 3킬로옴, R2는 2킬로옴이에요 / 출력 전압은 몇 볼트일까요?
- 화면: 「퀴즈」, 세로 회로 「10V」 「R1 3킬로옴」 「R2 2킬로옴」 출력 「? V」, 3초 카운트다운
- 움직임: 숫자를 말할 때 값, 카운트다운
- 멈춤: 3초

### L27B · 퀴즈 정답

- 읽기: [사 볼트|4V]예요. [십 곱하기 이 나누기 오|10 × 2 ÷ 5]는 [사|4]예요.

- 화면: 출력 「4V」, 아래 「10 × 2 ÷ (3 + 2) = 4V」

### L28 · 마무리

- 자막: 오늘은 직렬 저항이 전압을 나눠 가지는 / 전압 분배를 살펴봤어요 / 저항을 거꾸로 구하는 식과 퀴즈는 / 설명란의 블로그 글에 정리해 두었어요 / 여기까지 오셨다면 전압, 전류, 저항으로 / 회로를 읽는 기초를 갖춘 거예요
