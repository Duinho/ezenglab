# 저항 영상 장면표

## 공통 규칙

- **읽기** 줄은 타입캐스트에 넣는 문장이에요. 자막은 읽기 줄에서 아래 표기 규칙으로 바꿔 만들어요.
- 숫자는 소리를 한글로 직접 적어요(예: `[오 볼트|5V]`). 값·이름표는 한자어, 개수는 고유어(네 개, 두 배)로 읽어요.
- 천천히 읽기(`{천천히: …}`)는 쓰지 않아요(2026-11-11 팀장님 결정).
- **자막** 줄은 모든 장면에 써요. 주어·목적어와 서술어, 용어와 조사가 갈라지지 않게 뜻 단위로 끊어요.
- **의도** 줄은 그 장면이 무엇을 보여 주려는지 한 줄로 적은 거예요(읽지 않음, 화면에 쓰지 않음).
- 색띠 색은 영상 끝까지 똑같이 써요(원고 그림 r2_colorcode). 검정 0, 갈색 1, 빨강 2, 주황 3, 노랑 4, 초록 5, 파랑 6, 보라 7, 회색 8, 흰색 9, 오차 띠 금색·은색. 흰색 띠와 노랑 띠는 몸통 색(연한 베이지)과 구분되게 얇은 회색 테두리를 둘러요.
- 저항 그림은 원고 그림(r1~r16)의 모양을 따라 SVG로 다시 그려요. 사진은 쓰지 않아요. 몸통 연한 베이지, 다리 회색.
- 전류는 파란 점이 흐르는 모습으로, 열은 주황·빨강 물결로 그려요. 영상 끝까지 같은 표현을 써요.
- 글꼴은 페이퍼로지만 써요. 저항값은 장면표에 「1킬로옴」「220옴」처럼 적고, 화면·자막에서는 render.py 공통 변환(tools/video/text_notation.js)이 기호로 바꿔요. 「옴의 법칙」 같은 이름은 그대로 둬요. 「±」「×」「÷」「+」「=」는 써도 돼요.
- 숫자와 사실은 원고에 있는 것만 써요. 토스터·히터의 소비 전력, 퓨즈선 저항, 뒷유리의 12V는 원고 11장이 계산을 보여 주려고 고른 값이라 화면 구석에 「예시 값」 이름표를 붙여요.
- 화면·자막에 강좌 번호를 쓰지 않아요. 다른 강의는 「키르히호프의 법칙 강의」「버튼 강의」처럼 이름으로만 말해요.

### 표기 규칙 (읽기 → 자막)

- `[읽는 소리|자막 글자]`: 그 자리만 따로 바꿔요.

### L04 · 좁은 회전문

- 의도: 놀이공원 입구 비유로 「미는 힘은 같아도 길이 좁으면 덜 지나간다」를 보여 준다
- 읽기: 놀이공원 입구를 떠올려 볼게요. 입구가 넓으면 [일 분에|1분에] [열 명이|10명이] 들어가요. 그런데 좁은 회전문 하나만 열면 [일 분에|1분에] [세 명만|3명만] 들어가요. 줄을 선 사람 수는 같은데, 길이 좁아서 지나가기 어려워진 거예요. 저항이 바로 이 회전문이에요. 미는 힘인 전압이 같아도, 길을 좁히면 지나가는 양인 전류가 줄어요.
- 자막: 놀이공원 입구를 떠올려 볼게요 / 입구가 넓으면 1분에 10명이 들어가요 / 그런데 좁은 회전문 하나만 열면 / 1분에 3명만 들어가요 / 줄을 선 사람 수는 같은데, / 길이 좁아서 지나가기 어려워진 거예요 / 저항이 바로 이 회전문이에요 / 미는 힘인 전압이 같아도, / 길을 좁히면 지나가는 양인 전류가 줄어요
- 화면: 원고 r1_gate처럼 왼쪽 넓은 입구(사람 줄, 「1분에 10명」), 오른쪽 위에서 내려다본 회전문(「1분에 3명」). 끝에 회전문 그림 옆에 저항 그림, 「미는 힘 = 전압」 「지나가는 양 = 전류」 이름표
- 움직임: "넓으면"에서 사람이 술술 들어감, "회전문 하나만"에서 회전문이 돌며 한 칸에 한 명씩, "같은데"에서 두 줄의 길이가 같다는 표시, "회전문이에요"에서 회전문이 저항 그림으로 바뀜, "전압이"·"전류가"에서 이름표
- 메모: 사람은 머리·몸통·팔다리가 이어진 사람 모양으로 그려요(막대 인형 금지, 전자 부품 110 수정 3).

### L05 · 숫자로 보면 열 배

- 의도: 같은 전압에서 저항이 10배면 전류가 10분의 1이 된다는 것을 결과 숫자 두 개로 보여 준다
- 읽기: 숫자로도 볼게요. 같은 [오 볼트|5V]에 [백 옴|100옴] 저항을 달면 [오십 밀리암페어|50mA]가 흘러요. [일 킬로옴|1킬로옴]을 달면 [오 밀리암페어|5mA]만 흘러요. 저항이 [열 배가|10배가] 되니, 전류는 [십분의 일로|10분의 1로] 줄었어요.
- 자막: 숫자로도 볼게요 / 같은 5V에 100옴 저항을 달면 / 50mA가 흘러요 / 1킬로옴을 달면 5mA만 흘러요 / 저항이 10배가 되니, / 전류는 10분의 1로 줄었어요
- 화면: 위아래 두 줄 회로. 윗줄 「5V → 100옴 → 50mA」(굵은 파란 점 흐름), 아랫줄 「5V → 1킬로옴 → 5mA」(가는 흐름). 오른쪽에 「저항 ×10 → 전류 1/10」
- 움직임: "백 옴"에서 윗줄, "오십 밀리암페어"에서 점이 많이 흐름, "일 킬로옴"에서 아랫줄과 점이 드문드문, "열 배가"에서 오른쪽 글이 나타남

### L06 · 생김새: 다리, 몸통, 색띠

- 의도: 손에 쥐는 저항의 세 부분과 「극성이 없다」를 보여 준다
- 읽기: 손에 쥐는 저항은 대부분 이렇게 생겼어요. 양쪽으로 나온 금속선은 다리예요. 브레드보드나 기판에 꽂아요. 가운데 몸통 안에는 전류를 방해하는 재료가 들어 있어요. 몸통의 색띠는 저항값과 오차를 알려 줘요. 그리고 저항은 극성이 없어요. [엘이디|LED]와 달리 어느 쪽으로 꽂아도 똑같이 동작해요.
- 자막: 손에 쥐는 저항은 대부분 이렇게 생겼어요 / 양쪽으로 나온 금속선은 다리예요 / 브레드보드나 기판에 꽂아요 / 가운데 몸통 안에는 / 전류를 방해하는 재료가 들어 있어요 / 몸통의 색띠는 저항값과 오차를 알려 줘요 / 그리고 저항은 극성이 없어요 / LED와 달리 어느 쪽으로 꽂아도 / 똑같이 동작해요
- 화면: 원고 r3_anatomy처럼 저항 한 개를 크게, 「다리(리드선)」 「몸통」 「색띠」 이름표. 끝에 브레드보드에 저항을 한 번은 이쪽, 한 번은 반대로 꽂은 그림 두 개, 둘 다 「동작」
- 움직임: "다리예요"에서 다리 반짝, "몸통 안에는"에서 몸통이 반투명해지며 안쪽 재료, "색띠는"에서 띠 반짝, "어느 쪽으로"에서 저항이 뒤집혀 꽂힘

### L07 · 색깔 암호표

- 의도: 숫자를 색으로 적는 이유와 0부터 9까지의 색 순서를 한 줄로 보여 준다
- 읽기: 저항값은 숫자 대신 색깔 띠로 적어요. 몸통이 작아서 숫자를 쓰기 어렵고, 어느 쪽으로 돌려도 보이게 하려는 거예요. 색과 숫자의 약속은 [영부터 구까지|0부터 9까지] 정해져 있어요. 검, 갈, 빨, 주, 노, 초, 파, 보, 회, 흰. 검정이 [영|0], 갈색이 [일|1]이고, 그다음은 무지개 순서를 따라가요.
- 자막: 저항값은 숫자 대신 색깔 띠로 적어요 / 몸통이 작아서 숫자를 쓰기 어렵고, / 어느 쪽으로 돌려도 보이게 하려는 거예요 / 색과 숫자의 약속은 / 0부터 9까지 정해져 있어요 / 검, 갈, 빨, 주, 노, 초, 파, 보, 회, 흰 / 검정이 0, 갈색이 1이고, / 그다음은 무지개 순서를 따라가요
- 화면: 원고 r2_colorcode처럼 색 칸 열 개를 가로로(칸 위에 숫자 0~9, 아래에 한 글자 이름 검 · 갈 · 빨 · 주 · 노 · 초 · 파 · 보 · 회 · 흰)
- 움직임: "어느 쪽으로 돌려도"에서 작은 저항이 돎, "검, 갈, 빨"부터 말하는 순서대로 칸이 하나씩 켜짐, "무지개 순서를"에서 빨~보 칸 위에 무지개 곡선

### L08 · 남색은 어디 갔지? (쇼츠 S1)

- 코덱스 수정 2026-11-19: 쇼츠 두 판 첫 자막의 마지막 한 낱말이 떨어지지 않도록 해당 문장만 글자 크기를 조정해 한 줄에 배치합니다. 대사·자막 문장·시각·움직임은 보존합니다.
- 의도: 무지개 일곱 색과 비교해 남색이 빠졌다는 「오, 그래?」 꼭지로 외우는 요령을 준다
- 읽기: 그런데 무지개는 빨주노초파남보잖아요. 저항 색띠에는 남색이 없어요. 파랑 [육|6] 다음이 바로 보라 [칠|7]이에요. 남색은 파랑과 비슷해서 뺐다고 기억하면 헷갈리지 않아요. 다만 이건 외우기 위한 요령이에요. 실제로 남색이 빠진 이유를 밝힌 기록은 찾지 못했어요.
- 자막: 그런데 무지개는 빨주노초파남보잖아요 / 저항 색띠에는 남색이 없어요 / 파랑 6 다음이 바로 보라 7이에요 / 남색은 파랑과 비슷해서 뺐다고 기억하면 / 헷갈리지 않아요 / 다만 이건 외우기 위한 요령이에요 / 실제로 남색이 빠진 이유를 밝힌 기록은 / 찾지 못했어요
- 화면: 위쪽 무지개 일곱 칸(빨 · 주 · 노 · 초 · 파 · 남 · 보), 아래쪽 L07 색 칸 중 빨~보 다섯 칸을 맞춰 놓음. 남 칸이 아래 줄에서 빈 자리로 빠짐, 파랑 6과 보라 7이 붙음. 끝에 구석 작은 글씨 「외우기 요령」 이름표
- 움직임: "빨주노초파남보"에서 무지개 칸이 차례로, "남색이 없어요"에서 남 칸이 흔들리며 위로 빠져나감, "파랑 육 다음이"에서 파랑과 보라 칸이 붙음, "외우기 위한 요령"에서 이름표

### L09 · 4띠 저항 읽기 (쇼츠 S1)

- 의도: 여는 질문의 갈 · 검 · 빨 · 금을 네 단계로 풀어 1킬로옴이라는 답을 회수한다

### L10 · 오차 ±5%의 뜻

### L16 · 저항이 견디는 열: 전력 정격

- 의도: 저항이 전류를 막으며 열을 낸다는 것, 견디는 전력이 정해져 있다는 것을 결과 숫자 둘로 보여 준다

- 자막: 저항은 전류를 막으면서, / 그 에너지를 열로 바꿔요 / 열이 너무 많으면 / 뜨거워져 타거나 값이 변해요 / 그래서 저항마다 견딜 수 있는 전력이 / 정해져 있어요 / 실습에 흔히 쓰는 건 1/4W예요 / 앞의 LED 회로에 단 220옴은 / 0.04W 정도라 충분해요 / 그런데 5V에 100옴만 바로 이으면 0.25W, / 한계에 딱 닿아요 / 이럴 땐 1/2W 이상을 써서 / 여유를 둬요
- 화면: 원고 r8_power처럼 크기가 다른 저항 세 개(1/4W · 1/2W · 1W, 클수록 몸통이 큼). 가운데 「1/4W = 0.25W」 눈금 막대, 막대 위에 「LED 회로 220옴 0.04W」(짧은 초록 막대)와 「5V에 100옴 0.25W」(끝까지 찬 빨강 막대)

- 메모: 0.041W는 귀로 듣기 쉽게 「영 점 영사 와트 정도」로 읽어요. 식 P = V × I = I² × R = V² ÷ R은 블로그 7장으로 넘겨요.

### L17 · 직렬: 한 줄로 이으면 더해요

- 의도: 좁은 길이 길어지면 저항이 더해진다는 것을 회전문 두 개로 보여 준다

### L18 · 병렬: 나란히 이으면 길이 늘어나요
